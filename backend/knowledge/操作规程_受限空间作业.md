# 受限空间作业安全操作规程

## 第一章 编制目的与适用范围

### 一、编制目的

为规范公司受限空间作业的安全管理，有效防范和遏制中毒、缺氧窒息、燃爆等事故的发生，保障作业人员生命安全，依据《中华人民共和国安全生产法》《工贸企业有限空间作业安全规定》（应急管理部令第13号）及GB 30871-2022《危险化学品企业特殊作业安全规范》等法律法规和标准规范，结合公司实际，制定本规程。

### 二、适用范围

本规程适用于公司区域内所有受限空间作业。受限空间指进出口受限但人员可以进入、通风不良、可能存在易燃易爆和有毒有害物质或缺氧、对进入人员的身体健康和生命安全构成威胁的封闭、半封闭设施及场所，常见包括：

1. 反应釜、合成塔、储罐、槽车、容器、管道等设备设施内部；
2. 污水处理池、集水井、污水管道、检查井、地沟、地坑等地下设施；
3. 锅炉、炉膛、烟道、料仓、料斗、除尘器、烟囱等构筑物内部；
4. 地下室、人孔、观察孔、隐蔽空间等长期不通风的场所。

## 第二章 危险有害因素分析

### 一、中毒与缺氧窒息危险

1. 中毒：受限空间内可能积存硫化氢、一氧化碳、氨、氯气、苯、甲醇蒸气等有毒有害气体，短时间接触即可造成人员中毒甚至死亡，硫化氢浓度达到1000毫克每立方米以上可致人"电击样"死亡；
2. 缺氧窒息：空间内氧气含量低于19.5%即为缺氧环境，氮气、二氧化碳等惰性气体置换或物料耗氧可造成缺氧，人员进入后短时间内即会昏迷窒息；
3. 二次伤害：空间内残留物料遇扰动继续挥发、放热反应耗氧、腐烂发酵产气等，可在作业过程中动态改变环境条件。

### 二、燃爆及其他危险

1. 燃爆：空间内可燃气体、蒸气或粉尘与空气形成爆炸性混合物，遇明火、静电、摩擦火花发生爆炸；
2. 淹溺：污水池、水井等空间内液位上涨或突然放水，可造成人员淹溺；
3. 坍塌掩埋：料仓、料斗内的物料结块、架桥后突然塌落，可掩埋作业人员；
4. 触电与机械伤害：空间内临时照明漏电、搅拌器等转动设备意外启动、工具坠落等造成伤害；
5. 盲目施救：这是受限空间事故伤亡扩大的最主要原因，一人遇险、多人施救、群死群伤的教训极为深刻。

## 第三章 作业前准备

### 一、作业审批与辨识

1. 受限空间作业实行许可制度，作业前必须办理《受限空间安全作业证》，严禁无证进入；
2. 属地单位应对受限空间进行风险辨识，确认空间名称、位置、可能存在的危险物质及危害因素，制定针对性的安全措施；
3. 作业证由属地单位负责人和安全管理部门审批，作业证有效期不超过24小时，作业中断超过30分钟应重新进行气体分析；
4. 对辨识出的风险较高或情况不明的受限空间，应先行制定专项作业方案，经审批后实施。

### 二、隔离、清洗与置换

1. 作业前应将受限空间与生产系统可靠隔离，加装盲板或拆除一段管线，严禁以关闭阀门代替盲板；
2. 空间内搅动设备、传动装置的电源应切断并挂"禁止合闸、有人工作"警示牌，必要时取下熔断器上锁管理；
3. 对盛装过腐蚀性、毒性、易燃易爆物料的受限空间，应先放空、排净、蒸煮、清洗、吹扫、置换；
4. 置换应优先采用蒸汽或氮气吹扫后充分通风，禁止直接向内输送氧气。

### 三、通风与气体检测

1. 受限空间作业前和作业过程中必须保持持续通风，优先采用自然通风，不足时采用防爆型机械通风，风管应伸至底部或作业面；
2. 作业前30分钟内必须进行气体检测，检测顺序为氧气、可燃气体、有毒气体，检测数据记入作业证并由检测人签字；
3. 合格标准：氧含量19.5%～21%（富氧环境中不应大于23.5%）；可燃气体浓度不大于爆炸下限的10%；硫化氢不大于10毫克每立方米，一氧化碳不大于20毫克每立方米，其他有毒气体不超过GBZ 2.1规定的职业接触限值；
4. 检测应覆盖空间的上、中、下各部位及死角，垂直空间由上而下、水平空间由外而内逐点检测；作业期间每隔2小时至少复测一次，必要时连续监测；
5. 气体检测仪应在校验有效期内，检测人员应站在上风侧，禁止到空间内取样。

### 四、安全交底与照明电气

1. 作业前向全体作业人员、监护人进行安全交底，明确危险因素、安全措施、联络信号和应急方法，签字确认；
2. 空间内照明电压应不大于36伏，潮湿、狭小空间应不大于12伏，使用安全电压行灯和防爆灯具；
3. 空间内使用的电动工具必须装设漏电保护器，电缆完好无破损；带入的工具、材料应登记，作业结束时清点核对，防止遗留在空间内。

## 第四章 作业步骤与安全要点

### 一、进出与监护管理

1. 受限空间出入口处应设专职监护人，监护人不得离岗，应掌握空间内作业人员数量和状态，保持不间断联络；
2. 每名进入人员应登记进出时间，佩戴安全帽和身份标识，出空间时注销；监护人清点人数，做到进出一致；
3. 人员进出通过人孔、井口时使用安全梯或三脚架，必要时系上安全绳，安全绳一端固定在空间外可靠挂点上；
4. 监护人发现气体超标、人员不适、通风失效等异常时，应立即发出撤离信号，组织空间内人员全部撤出，未经重新检测确认不得再进入。

### 二、作业过程安全要点

1. 作业期间保持自然和机械通风连续运行，禁止向空间内通氧气；人员轮换休息时通风不得中断；
2. 空间内严禁吸烟，严禁使用明火照明和取暖，动火作业须另行办理动火作业证，并保证两者安全措施同时落实；
3. 空间内作业人员如出现头晕、恶心、心慌、乏力等不适症状，应立即撤离，不得强行坚持；
4. 对物料可能流出的空间，外部应设置挡板、闸板等措施，防止物料涌入伤人；
5. 高处进入受限空间（如罐顶入孔）时，同时落实高处作业防坠落措施；涉及吊装、动火、临时用电的，同步办理相应作业许可。

### 三、作业结束收尾

1. 作业结束后清点人员和工具、材料，确认无人员、物品遗留后方可封闭人孔；
2. 拆除盲板、恢复系统前应确认现场条件，按工艺要求办理恢复手续；
3. 恢复被拆除的护栏、盖板等安全设施，清理现场，作业证归档保存不少于一年。

## 第五章 个人防护装备要求

1. 进入人员应佩戴安全帽、防护服、防护手套和防砸防滑鞋，根据危险物质特性选用防化服、防化靴；
2. 经通风检测合格的低风险空间可佩戴正压式过滤呼吸防护用品，氧气不足、有毒气体超标或情况不明的空间必须佩戴正压式空气呼吸器或长管呼吸器，严禁佩戴普通过滤式防毒面具进入；
3. 必要时作业人员应系安全绳、救生索，配备对讲机或防爆通讯工具；
4. 监护人和应急救援人员应配备便携式气体检测报警仪、正压式空气呼吸器和快速连接的安全带、三脚架等救援器材，并保持完好可用。

## 第六章 应急处置措施

### 一、应急准备

1. 作业前应制定应急处置方案并交底，明确报警方式、救援分工和送医路线；
2. 现场应配备正压式空气呼吸器、救生绳、三脚架、担架、急救药箱等应急器材，监护人负责检查保管。

### 二、应急处置

1. 发现空间内人员中毒、窒息或遇险时，监护人应立即报警呼救，同时利用安全绳、三脚架等器材在做好自身防护的前提下实施救援，严禁未佩戴呼吸器盲目进入施救；
2. 多人遇险时，应先报告、后施救，组织佩戴空气呼吸器的救援人员分批轮换进入，防止伤亡扩大；
3. 将遇险人员救出后，迅速移至上风向空气新鲜处，解开衣领保持呼吸道通畅，呼吸心跳停止的立即进行心肺复苏，并拨打120送医；
4. 空间内发生燃爆、火灾时，立即切断电源、气源，撤离人员后按火灾事故应急处置程序处置；
5. 事故发生后保护现场，及时上报，配合调查。

## 第七章 相关法规标准与要点提示

1. 主要法规标准依据：《中华人民共和国安全生产法》第四十一条、第一百零二条关于有限空间作业的规定；《工贸企业有限空间作业安全规定》（应急管理部令第13号）；GB 30871-2022《危险化学品企业特殊作业安全规范》；GBZ/T 205《密闭空间作业职业危害防护规范》。
2. 核心口诀：先辨识、再审批，先隔离、再置换，先通风、再检测，先防护、再进入，有监护、不断联，遇险情、快撤离，不盲救、先报告。各单位应将口诀制成牌板悬挂于受限空间作业现场醒目位置。
3. 关键数据速查：氧含量合格范围19.5%～21%；可燃气体浓度不大于爆炸下限的10%；硫化氢职业接触限值为10毫克每立方米（最高容许浓度）；一氧化碳时间加权平均容许浓度为20毫克每立方米。
4. 典型致害气体来源提示：硫化氢多产生于污泥发酵、含硫物料腐败，比空气重、易积聚于低洼处；一氧化碳多来自不完全燃烧和煤气设施；氮气置换后的容器极易缺氧；粮食、木材等有机物仓储发酵可产生二氧化碳并造成缺氧窒息。
5. 本规程未尽事宜，按国家现行法律法规、标准规范和公司应急预案执行；作业中遇到规程未涵盖的新情况，应立即停止作业并报安全管理部门评估后确定处置方案，严禁擅自处置。

## 第八章 附则

1. 本规程由公司安全管理部门负责解释和修订；
2. 各单位应组织受限空间作业相关人员学习本规程并考核，未经培训考核合格不得承担作业、监护和审批职责；
3. 违反本规程的按公司安全生产奖惩制度处理，严禁违章指挥、违章作业、违反劳动纪律；
4. 本规程自发布之日起施行。
