# 动火作业安全操作规程

## 第一章 编制目的与适用范围

### 一、编制目的

为加强公司动火作业的安全管理，规范动火作业行为，有效控制和消除动火作业过程中的火灾、爆炸、灼烫等事故风险，保障作业人员生命安全和企业财产安全，依据《中华人民共和国安全生产法》《中华人民共和国消防法》《危险化学品安全管理条例》及GB 30871-2022《危险化学品企业特殊作业安全规范》等法律法规和标准规范，结合公司生产实际，制定本规程。

### 二、适用范围

本规程适用于公司所属各生产装置区、储罐区、辅助生产区及仓库、办公区域内所有临时性动火作业，主要包括：

1. 焊接、切割作业：电弧焊、气焊、气割、氩弧焊、等离子切割等；
2. 磨削作业：砂轮打磨、角磨机切割、金属喷砂等可能产生火花和高温颗粒的作业；
3. 明火加热作业：使用喷灯、火炉、加热炉等明火设备的作业；
4. 其他作业：钻探、破碎、凿削等可能产生火花、炽热表面或熔融金属的作业。

按照作业危险程度，动火作业分为特级动火、一级动火和二级动火三个等级。特级动火指在运行状态下的易燃易爆生产装置、罐区、管道等重要部位及其他具有特殊危险场所进行的动火作业；一级动火指在易燃易爆区域进行的动火作业；二级动火指在非易燃易爆区域进行的动火作业。动火等级由审批部门在办证时根据作业环境和风险程度确定，必要时可升级管理。

## 第二章 危险有害因素分析

### 一、火灾爆炸危险

动火作业产生的火焰、电弧、火花及炽热表面温度可达数千摄氏度，一旦接触可燃气体、可燃液体、可燃粉尘或可燃固体，极易引发火灾或爆炸事故。重点风险情形包括：

1. 动火点周围存在未清理的可燃物，或与易燃易爆生产装置、储罐区的安全距离不足，火花飞溅引燃周围物料；
2. 对盛装过易燃易爆物料的设备、管道动火前未进行彻底置换、清洗、分析，残留物料挥发形成爆炸性混合气体，遇火源发生化学爆炸；
3. 动火过程中可燃物料串入动火的设备、管道，或邻近装置发生泄漏，可燃气体扩散至动火点遇火花引爆；
4. 电焊机接地不良、回路线连接不规范，电流通过设备管线形成回路产生电火花，引燃管线内或周边可燃物；
5. 动火点下方或周边地沟、下水井、电缆沟内积存可燃气体或可燃液体，火花落入引发爆炸。

### 二、其他危险有害因素

1. 灼烫：焊接熔渣、飞溅火花、炽热工件、火焰等可造成人员皮肤灼伤和眼睛灼伤；
2. 触电：电焊机漏电、电缆绝缘破损、潮湿环境作业、防护用品缺失等可造成人员触电伤害；
3. 中毒窒息：焊接烟尘、臭氧、锰及其化合物等有害物质积聚，受限或半受限空间内通风不良，可造成人员中毒或窒息；
4. 高处坠落：在平台、脚手架、屋顶等高处进行动火作业时，可能发生高处坠落事故；
5. 物体打击与机械伤害：切割工件坠落、砂轮破碎飞溅、设备意外启动等造成伤害。

## 第三章 作业前准备

### 一、作业审批

1. 动火作业实行许可制度，作业前必须办理《动火安全作业证》，严禁无证动火、一证多用、涂改转让和异地使用；
2. 特级动火作业证由公司分管安全负责人或总工程师审批，一级动火作业证由安全管理部门负责人审批，二级动火作业证由车间（单位）负责人审批，审批人应到现场核实安全措施落实情况；
3. 作业证有效期：特级、一级动火作业证有效期不超过8小时；二级动火作业证有效期不超过72小时；作业中断超过30分钟继续作业前，应重新确认现场条件和气体分析结果；
4. 作业证应注明动火等级、动火部位、作业内容、动火人、监护人、有效期及安全措施等内容，一式三联，交出方、动火人、监护人各执一份，作业现场必须留存。

### 二、隔离与置换

1. 动火前应将动火设备、管道与生产系统可靠隔离，采用加装盲板或拆除一段管线的方式，严禁以关闭阀门代替盲板隔离；
2. 盛装过易燃易爆物料的设备、管道动火前应进行蒸煮、清洗、吹扫、置换处理，置换合格后方可交出动火；
3. 动火点周围10米范围内的可燃物应清理干净，垂直方向下方应同时清理；无法清理的可燃物应采取防火毯覆盖、钢板隔离、湿布保护等措施；
4. 地面、设备表面及下水井、地沟、电缆沟等可能积存可燃气体的部位，应采取封堵、覆盖、注水等措施，防止火花落入。

### 三、气体分析与检测

1. 动火前30分钟内必须使用符合标准的可燃气体检测仪进行取样分析，分析数据如实记入作业证，分析人签字确认；
2. 可燃气体浓度合格标准：当被测气体爆炸下限大于等于4%时，其浓度应不大于0.5%（体积分数）；当爆炸下限小于4%时，其浓度应不大于0.2%（体积分数）；
3. 取样点应具有代表性，重点检测动火部位内部、周围低洼处、沟坑死角等可燃气体易积聚位置；
4. 作业期间监护人应定时复测气体浓度，作业中断后恢复作业前必须重新分析，发现浓度超标应立即停止作业、撤离人员。

### 四、安全交底与监护

1. 作业前，属地单位应向作业人员进行安全技术交底，明确作业内容、危险因素、安全措施、应急处置方法和逃生路线，交底双方签字确认；
2. 动火作业必须设专职监护人，监护人应熟悉现场工艺流程和应急处置方法，经培训考核合格，作业期间不得脱岗、串岗或从事与监护无关的工作；
3. 现场应配备不少于2具8公斤干粉灭火器，并根据需要配备消防水带、蒸汽带、灭火毯、消防水源等，消防水压力应保证随时可用；
4. 作业区域应设置警戒线或警示标志，无关人员不得进入。

## 第四章 作业步骤与安全要点

### 一、一般安全要求

1. 坚持"三不动火"原则：没有经批准的动火作业证不动火、监护人不在现场不动火、防火措施不落实不动火；
2. 作业人员应持有有效的特种作业操作证，禁止无证人员从事焊接切割作业；
3. 五级风（含）以上天气，原则上禁止露天动火作业；确因生产需要动火的，应采取可靠的防风挡火措施并升级一级管理；
4. 动火作业与受限空间作业、高处作业、吊装作业等交叉进行时，应同时办理相应作业许可，统筹落实叠加风险的防范措施；
5. 附近生产装置发生泄漏、报警或工艺异常时，应立即停止动火，撤出人员，待查明原因并消除隐患后方可恢复作业。

### 二、焊接与切割作业安全要点

1. 电焊机应放置在干燥、通风、平稳处，外壳可靠接地（接零），焊把线、地线绝缘完好无破损，严禁利用金属结构、设备管道、轨道等代替焊接地线；
2. 气焊气割作业中，氧气瓶与乙炔气瓶应分开存放，两瓶间距不小于5米，气瓶与明火作业点的距离不小于10米；乙炔瓶必须直立放置并装设防回火装置，严禁卧放、倒放使用；
3. 焊割软管应完好无泄漏、无老化，接头卡固牢靠，作业中如遇软管着火应立即关闭瓶阀切断气源；
4. 焊割作业中如遇设备管道异常振动、声响、气味，或可燃气体报警仪报警，应立即停止作业、熄灭火源并撤离现场；
5. 高处动火作业时，作业点下方应设置接火盆、铺设防火毯，划定火花飞溅警戒区域，并设专人监视下方情况，防止火花引燃可燃物或灼伤下方人员。

### 三、作业过程监护与收尾要点

1. 监护人应全程监视作业现场和周围环境变化，及时提醒并制止作业人员的不安全行为，发现异常立即叫停作业；
2. 作业间断或结束后，动火人和监护人应共同检查现场，确认无残留火种、阴燃点后方可离开，必要时留守观察30分钟以上；
3. 作业结束后应及时清理现场，做到工完、料尽、场地清，拆除临时电源、气源，动火作业证由安全管理部门归档保存，保存期限不少于一年。

## 第五章 个人防护装备要求

1. 焊工应穿戴阻燃防护服、焊接防护面罩、防护手套、绝缘鞋等，禁止穿着化纤衣物进行动火作业；
2. 进行打磨、切割、凿削作业时，应佩戴防护眼镜或防护面屏，防止飞溅物伤害眼睛和面部；
3. 在受限空间内动火时，应随身携带便携式可燃气体、氧气及有毒气体检测报警仪，必要时佩戴正压式空气呼吸器或长管呼吸器；
4. 高处动火作业应系挂符合国家标准的安全带，安全带高挂低用，挂点牢固可靠，并落实防坠落措施；
5. 作业前应逐项检查可燃气体检测报警仪、消防器材、防护装备的完好有效性，发现失效立即更换，严禁带病使用。

## 第六章 应急处置措施

### 一、初起火灾处置

1. 发现火情，监护人应立即下令停止作业、切断气源和电源，组织人员使用现场灭火器、消防水实施扑救，同时报告属地负责人和应急值班室；
2. 火势无法控制时，应立即撤离现场及周边人员，划定警戒区域，拨打119报警，并启动公司火灾事故应急预案；
3. 可燃气体泄漏着火时，在未切断气源前不得盲目扑灭火焰，防止气体继续积聚发生二次爆炸，应优先关阀断源、冷却周围设备；
4. 处置过程中应结合物料特性正确选用灭火介质，遇水反应物料的火灾严禁用水扑救。

### 二、人员伤害处置

1. 发生人员灼烫伤时，应立即用大量清洁流动冷水冲洗冷却伤处，小心脱去或剪开粘连衣物，不要涂抹药物，及时送医治疗；
2. 发生触电时，应先切断电源或用干燥绝缘物挑开电线，使触电者脱离电源，再实施救援；对心跳呼吸骤停者立即进行心肺复苏，并持续至医护人员到达；
3. 发生中毒窒息时，严禁盲目施救，救援人员应佩戴正压式空气呼吸器、系好救生绳后方可进入现场施救，同时呼叫医疗救护；
4. 事故发生后应保护现场，及时报告，配合调查。

## 第七章 附则

1. 本规程由公司安全管理部门负责解释，并根据法规标准变化和生产实际适时修订；
2. 各车间（单位）应组织员工学习本规程并进行考核，考核不合格者不得参与动火作业；
3. 违反本规程规定的，按照公司安全生产奖惩制度追究相关人员责任，造成事故的依法依规严肃处理；
4. 本规程自发布之日起施行，原有相关规定与本规程不一致的，以本规程为准。
