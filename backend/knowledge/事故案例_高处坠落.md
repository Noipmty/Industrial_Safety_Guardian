# 某建筑公司在建厂房高处坠落事故

## 一、事故概况

某年11月6日9时40分许，某建筑公司承建的某装备制造产业园一期厂房项目工地，一名作业人员在2层钢结构平台临边处安装彩钢板时，未系挂安全带，失足从约9米高临边洞口坠落至地面，经抢救无效死亡。事故直接经济损失约135万元，属于一般生产安全责任事故。

事发项目总建筑面积约2.6万平方米，主体为单层钢结构厂房，局部二层混凝土框架辅助用房，事发时主体结构已完成，正在进行屋面彩钢板和二层辅助用房施工作业。涉事劳务分包队伍共32人，其中多名人员未经过系统的入场安全教育。

## 二、事故经过

11月6日7时30分，劳务班组组长周某召开班前会，安排8名工人到二层辅助用房楼面进行彩钢板安装作业。班前会仅交代了当天的工作量和进度要求，未针对高处作业进行安全交底，也未检查作业人员安全带配备情况。

8时10分，作业人员王某（男，43岁，安装工，工龄2个月）等4人通过室内楼梯进入二层楼面。该楼面临边按照规范应设置1.2米高防护栏杆，但事发部位的临边防护栏杆因前一天吊运材料需要，被工人临时拆除，拆除后未恢复，也未设置任何警戒标志和安全网。

9时30分，王某为追赶进度，独自到平台边缘搬运彩钢板。9时40分许，王某在弯腰拽拉钢板时身体失衡，从被拆除栏杆的临边洞口坠落到一层混凝土地面，坠落高度约9米。同班组人员听到响声后立即跑到一层查看，发现王某头部大量出血、昏迷不醒，随即拨打120急救电话并报告项目部。

9时52分，120救护车到达现场，对王某实施紧急救治后送医院抢救。当日13时15分，王某因重度颅脑损伤经抢救无效死亡。事故发生后，项目部立即停工，保护现场并按规定向当地应急管理部门报告。

## 三、直接原因分析

1. 王某违反高处作业安全操作规程，在9米高临边部位作业未系挂安全带，且未佩戴安全帽下颚带（坠落过程中安全帽脱落），缺乏最基本的个体防坠落保护；
2. 事发临边防护栏杆被临时拆除后未及时恢复，未设置警戒线和警示标志，未采取其他替代防护措施，临边洞口完全敞开，形成致命的坠落通道；
3. 劳务人员安全意识和自保互保意识严重缺失，班组管理混乱，工人可以随意拆除安全防护设施而无人纠正。

## 四、间接与管理原因分析

1. 安全教育培训严重缺失。王某入职仅2个月，未经三级安全教育培训考核即上岗作业，劳务分包单位未按规定对农民工开展入场教育，项目总包单位对分包人员持证和培训情况审核把关不严；
2. 安全技术交底流于形式。班前会只讲进度不讲安全，未针对彩钢板安装作业的高处坠落风险进行书面交底和签字确认；
3. 现场安全防护动态管理缺位。项目对"因施工需要临时拆除防护设施"未建立审批和恢复制度，防护栏杆拆除后无人组织恢复，专职安全员当日未对二层作业面进行巡查；
4. 劳务分包管理失控。总包单位对分包队伍实行"以包代管"，未将分包人员纳入统一的安全管理体系；分包队伍负责人重生产、轻安全，未配备足够的防坠落用品；
5. 项目安全生产责任制不落实。项目经理长期未组织安全检查例会，隐患排查台账记录与现场实际严重不符，存在应付检查、弄虚作假行为。

## 五、责任追究与处理结果

依据《中华人民共和国安全生产法》《生产安全事故报告和调查处理条例》等法律法规，事故调查组认定该起事故是一起生产安全责任事故，处理结果如下：

1. 劳务分包单位负责人周某违章指挥、疏于管理，对事故发生负有直接管理责任，给予撤职处理，并处罚款；
2. 王某本人违反操作规程、未系安全带，对事故发生负有直接责任，鉴于其已在事故中死亡，不再追究责任；
3. 劳务分包公司未落实安全生产主体责任，被处罚款20万元，并纳入建筑市场不良行为记录；
4. 总包单位项目部专职安全员赵某未履行巡查职责，给予记大过处分并调离岗位；项目经理孙某履行职责不力，给予降职处分并处罚款；
5. 总包公司作为施工总承包单位，被处罚款50万元，暂停投标资格3个月，纳入重点监管名单；
6. 监理单位未有效履行安全监理职责，被警告并处罚款，项目总监理工程师被记过处分。

## 六、防范与整改措施

1. 严格落实安全教育培训制度。所有进场人员必须经三级安全教育、考核合格并登记建档后方可上岗，实行实名制管理；新工人和转岗人员必须重新培训；
2. 强化班前安全活动和技术交底。班前会必须讲安全、交底必须书面化并签字确认，针对每个作业面的具体风险明确防护要求；
3. 建立安全防护设施动态管理制度。任何防护设施的拆除必须经项目经理批准、采取替代措施并限时恢复，未经批准擅自拆除的严肃处理；临边、洞口防护每周专项检查一次；
4. 加强高处作业管理。2米以上临边、悬空作业必须100%系挂安全带，实行"挂点检查、互检互纠"，配备水平生命线和防坠器，对违反者立即清退出场；
5. 压实总包对分包的统一管理责任。分包人员纳入总包安全管理体系统一培训、统一检查、统一考核，严禁"以包代管"；
6. 完善安全检查和隐患闭环整改机制，专职安全员每日巡查、项目部每周检查、公司每月督查，隐患整改做到责任、措施、资金、时限、预案"五落实"；
7. 项目部配齐配足安全防护用品，建立发放、领用、报废台账，确保人人合格佩戴。

## 八、事故链复盘与法规链接

### 一、事故链复盘

本起事故的事故链可概括为：新工人未经培训入场（准入失效）→ 临边防护被拆除未恢复（设施失效）→ 班前会未交代风险（教育失效）→ 现场无人巡查制止（监督失效）→ 作业人员未系安全带（最后防线失守）→ 坠落死亡。每一道防线都是普通的、低成本的措施，但全部同时失效，最终酿成悲剧。企业应以"防线思维"审视现场管理，确保任何时刻至少有两道独立防线处于有效状态。

### 二、法规标准链接

1. 《中华人民共和国安全生产法》第二十八条：生产经营单位应当对从业人员进行安全生产教育和培训，未经安全生产教育和培训合格的从业人员，不得上岗作业；
2. 《建设工程安全生产管理条例》第二十八条：施工单位应当对施工现场临边、洞口等危险部位设置明显的安全警示标志，并采取相应的安全防护措施；
3. JGJ 80《建筑施工高处作业安全技术规范》关于临边、洞口、攀登、悬空作业和操作平台的防护要求；
4. GB 6095《坠落防护 安全带》、GB 24543《坠落防护 安全绳》等个体防护装备标准；
5. 《建筑施工企业安全生产管理机构设置及专职安全生产管理人员配备办法》关于安全管理人员配备的规定。

### 三、同类事故多发环节自查清单

1. 临边、洞口防护设施是否完好，是否存在拆除后未恢复、验收后私自挪用的情况；
2. 高处作业人员是否百分之百经培训考核合格，特种登高作业人员是否持证；
3. 安全带配备数量是否满足作业人数需要，是否定期检查并按规定报废；
4. 交叉作业是否有统一协调和隔离防护措施；
5. 恶劣天气作业管控和停工复工确认是否严格执行。

### 四、安全防护费用与管理要点

1. 建筑施工企业应按规定足额提取和使用安全文明施工措施费，临边防护、安全网、安全带等费用单独列支、专款专用，不得作为竞争性费用随意压减；
2. 项目部应建立防护设施验收挂牌制度，防护栏杆、盖板、安全网经验收合格后挂设验收牌，注明验收人和日期，未经批准任何人不得拆除；
3. 劳务实名制通道应与安全培训档案联动，培训不合格、未建档人员门禁无法开通，从技术上杜绝未经教育人员进场作业；
4. 每周由项目经理带队开展一次全覆盖安全检查，对高处作业防护进行专项评分，评分结果与分包单位进度款支付挂钩。

## 九、事故教训与警示

1. 一根安全带、一道栏杆，就是生死线。9米坠落源于"未系安全带"与"护栏未恢复"两个细节的叠加，任何一项防护到位，事故都不会发生。企业必须把个体防护和临边洞口防护作为现场管理的底线要求，逐点核查、刚性执行；
2. 教育培训不能走过场。新工人未经培训就进入高处作业面，等于把人置于险境而不自知，培训必须与岗位风险一一对应，做到"不培训不上岗、不合格不上岗"；
3. "因施工需要临时拆除防护"是高处坠落事故的常见诱因，必须建立拆除审批、替代防护、限时恢复的闭环管理，杜绝"拆了就忘、拆了不管"；
4. 班组长是现场安全的第一道防线，班前会讲安全、作业中盯防护、收工时查隐患，要把安全责任压实到最小作业单元；
5. 总包、分包、监理各方必须形成安全责任链条上的相互制衡，任何一环失守都会导致事故，行业主管部门和企业在选择合作方时应把安全履约能力作为重要准入条件；
6. 施工企业应将本案例改编为农民工夜校警示教材，结合实景照片和动画还原事故过程，组织全员观看并签名确认；同时对在建项目开展临边洞口防护和三级教育落实情况的拉网式复查，复查结果书面报告建设单位和监理单位，主动接受各方监督；
7. 每年春秋两季应结合开工复工节点，组织高处作业防护专项检查评比，对防护达标班组给予流动红旗和物质奖励，让"防护到位"成为看得见的荣誉。
