# 高处作业安全操作规程

## 第一章 编制目的与适用范围

### 一、编制目的

为规范公司高处作业的安全管理，防范和减少高处坠落、物体打击等事故的发生，保障作业人员生命安全，依据《中华人民共和国安全生产法》《建筑施工高处作业安全技术规范》JGJ 80及GB 30871-2022《危险化学品企业特殊作业安全规范》等法律法规和标准规范，结合公司实际，制定本规程。

### 二、适用范围

本规程适用于公司区域内所有在坠落高度基准面2米及以上（含2米）有可能坠落的高处进行的作业，包括在建筑物、构筑物、设备设施、脚手架、平台、梯子、屋顶等部位进行的登高作业，以及检修、安装、清洁、取样等临时性高处作业。

按照作业高度，高处作业分为四个等级：作业高度在2米至5米时为一级高处作业；5米以上至15米时为二级高处作业；15米以上至30米时为三级高处作业；30米以上时为特级高处作业。直接引起坠落的客观危险因素有十一类，存在高温、低温、露天雨雪、临边、洞口、接近带电体等情形的，不得按上述等级计算，应按规定升级管理。

## 第二章 危险有害因素分析

### 一、高处坠落危险

1. 攀登作业中梯子不稳、踏步缺损、双手持物攀爬造成坠落；
2. 悬空作业中未系安全带或安全带挂点不牢、低挂高用，失稳坠落；
3. 操作平台超载、平台板铺设不实、护栏缺失导致人员和物料坠落；
4. 临边、洞口防护设施缺失、损坏或被擅自拆除，人员误入坠落；
5. 屋面作业坡度大、天窗孔洞未防护、采光带承重不足而踏穿坠落；
6. 脚手架搭设不规范、连墙件缺失、模板支架失稳造成整体坍塌坠落。

### 二、物体打击及其他危险

1. 高处作业的工具、材料、螺栓等坠落伤及下方人员；
2. 交叉作业中上层作业的坠物打击下层人员；
3. 高处动火作业与临时用电作业引发的火灾、触电风险叠加；
4. 大风、雷雨、高温、冰雪等恶劣天气引发的滑坠、雷击、中暑风险；
5. 登高设备（升降机、吊篮、移动平台）失效造成的伤害。

## 第三章 作业前准备

### 一、作业审批

1. 高处作业实行许可制度，作业前必须办理《高处安全作业证》，一级、二级高处作业证由车间（单位）负责人审批，三级、特级高处作业证由安全管理部门负责人及以上领导审批；
2. 作业证应注明作业地点、内容、高度、等级、有效期、作业人员和安全措施，有效期一般不超过7天，作业中断超过规定时间应重新确认安全条件；
3. 在易燃易爆区域高处动火、登高接近带电设备等，应同时办理相应作业许可。

### 二、人员条件确认

1. 患有高血压、心脏病、贫血、癫痫、恐高症等职业禁忌症人员，不得从事高处作业，作业前应确认人员身体条件；
2. 作业人员应经过安全教育培训，熟悉高处作业风险和防护方法，特种登高架设作业人员应持证上岗；
3. 作业前禁止饮酒，疲劳、情绪异常人员应暂停登高作业。

### 三、防护设施与工具检查

1. 作业前检查脚手架、操作平台、临边洞口防护、安全网、攀登设施等是否完好牢固，确认合格后方可作业；
2. 检查安全带、安全绳、安全帽等防护用品的外观和合格标识，发现破损、变形、超期的立即更换；
3. 检查随身工具是否装入工具袋，小型工具应系防坠绳，材料应捆绑牢靠；
4. 作业区域下方设置警戒区，悬挂警示标志，必要时设专人看护。

## 第四章 作业步骤与安全要点

### 一、攀登与行走安全要点

1. 上下攀登应使用牢固的梯子、爬梯或通道，禁止攀爬脚手架杆件、栏杆、管道、设备等非攀登设施；
2. 移动式梯子应放置稳固，与地面夹角以60度至70度为宜，梯脚有防滑装置，底部设专人扶护；人字梯应有可靠的拉撑装置；
3. 梯子踏步间距均匀、无缺损，单梯只能一人作业，禁止在梯子最上两级作业和双人同梯；
4. 高处行走应走安全通道和马道，禁止在横梁、管道、屋脊等无防护部位行走，确需通行时应设置生命线并系挂安全带。

### 二、悬空与平台作业安全要点

1. 悬空作业必须设置可靠的立足点，并系挂安全带；安全带应高挂低用，挂点牢固，不得将安全带系挂在移动、尖锐或强度不足的构件上；
2. 操作平台应经计算验收，显著位置标明允许荷载值，人员和物料总重不得超过设计荷载；
3. 平台板应铺满、铺稳、绑扎牢固，平台四周设置不低于1.2米的防护栏杆和18厘米高的挡脚板，挂设安全网；
4. 高处传递物料应使用绳索、滑轮或起重工具，严禁抛掷；边角料、废弃物应集中收集，防止坠落伤人。

### 三、临边洞口与交叉作业安全要点

1. 临边作业应设置防护栏杆和安全网，分层施工的楼梯口、电梯井口、预留洞口应设置盖板、护栏或安全网，设施不得擅自挪动和拆除，确需临时拆除的应经批准并采取替代措施，作业完毕立即恢复；
2. 交叉作业时，上下层作业位置应错开，不得处于同一垂直方向；无法错开的应设置隔离防护层，下层作业位置应处于上层作业坠落半径之外；
3. 拆除作业应自上而下进行，禁止上下同时拆除和数层同时拆除；
4. 六级风（含）以上、雷电、暴雨、大雾等恶劣天气，应停止露天高处作业和起重吊装配合的高处作业；雨雪天气后应先清扫、防滑、检查，再恢复作业。

## 第五章 个人防护装备要求

1. 作业人员必须正确佩戴安全帽，系紧下颚带，进入作业区任何人员不得赤脚、穿拖鞋、穿硬底鞋或带钉易滑的鞋；
2. 凡在2米及以上无可靠防护设施的高处作业，必须系挂符合GB 6095标准的安全带，安全带高挂低用，悬挂点牢固可靠，禁止用绳子捆绑替代；
3. 根据作业环境配备防滑鞋、绝缘鞋、护目镜、防坠器等，屋面作业应穿防滑鞋并铺设脚手板；
4. 高温季节合理安排作业时间，配备防暑降温用品；夜间作业应有充足照明。

## 第六章 应急处置措施

### 一、坠落事故处置

1. 发生人员高处坠落时，立即呼救并报告，不要随意搬动伤员，防止脊柱二次损伤；
2. 由经过急救培训的人员检查伤员意识、呼吸和出血情况，对出血伤口进行止血包扎，对骨折部位进行临时固定；
3. 对呼吸心跳停止者立即进行心肺复苏，同时拨打120送医；搬运伤员应使用担架、木板，保持脊柱平直。

### 二、其他情况处置

1. 人员悬吊在安全带上无法自行返回时，应尽快组织救援，防止悬吊创伤，超过15分钟悬吊可能造成休克甚至死亡；
2. 发生物体打击事故时，立即停工救人，保护现场，视伤情送医并上报；
3. 遇大风、雷雨等突发天气，应立即停止作业，组织人员有序撤离至安全地带；
4. 事故处置后保护现场，及时报告，配合调查分析。

## 第七章 相关法规标准与要点提示

1. 主要法规标准依据：《中华人民共和国安全生产法》第五十七条关于从业人员安全防护义务的规定；JGJ 80《建筑施工高处作业安全技术规范》；GB 30871-2022《危险化学品企业特殊作业安全规范》；GB 6095《坠落防护 安全带》；GB 2811《头部防护 安全帽》。
2. 分级管理速查：一级高处作业2米至5米；二级5米以上至15米；三级15米以上至30米；30米以上为特级。存在高温、低温、雨雪、临边、洞口、接近带电体等直接致害危险因素时，不应按上述等级分级，应按规定升级管理。
3. 安全带使用要点：优先选用五点式全身式安全带，作业时高挂低用，移动过程中不得失去保护，采用双钩交替方式转移挂点；每次使用前检查织带、缝线、金属件和缓冲包，发现割伤、烧蚀、开线立即报废；安全带受强力冲击后一律报废，不得继续使用。
4. 临边洞口防护速查：临边防护栏杆上杆高1.2米、中杆高0.6米、设18厘米高挡脚板；短边25厘米至50厘米的洞口用盖板覆盖固定，50厘米至150厘米的洞口设置防护栏杆或安全平网，150厘米以上洞口四周设防护栏杆并张挂安全网。
5. 恶劣天气控制指标：六级风（风速10.8米每秒）及以上禁止露天高处作业；雷电、暴雨、大雾天气停止作业；雨雪后先检查设施、再清扫防滑、后恢复作业。
6. 事故应急要点：发现人员坠落或悬吊，立即呼救并报告，不得随意搬动伤员；悬吊人员应在15分钟内解救至地面，防止悬吊创伤；救援使用担架、颈托等器材规范转运，同步拨打120送医。
7. 高处作业常见违章清单（对照自查）：不办票作业、代签作业票；不系安全带或低挂高用；攀爬非攀登设施；抛掷工具材料；擅自拆除防护设施；雨雪后未检查即作业；身体不适仍登高；下方警戒区无人值守。
8. 管理提示：各单位应将高处作业作为每日班前会必讲内容，对二级及以上高处作业实行"作业前照片确认"制度，将防护设施、安全带挂点拍照上传至安全管理平台，接受全员监督。
9. 本规程未尽事宜，按国家现行标准规范及公司相关制度执行；各单位可结合实际编制实施细则，报安全管理部门备案后实施。

## 第八章 附则

1. 本规程由公司安全管理部门负责解释和修订；
2. 各单位应组织高处作业人员学习本规程并考核合格，未经培训不得上岗；
3. 违反本规程的，按公司安全生产奖惩制度处理；
4. 本规程自发布之日起施行，原有规定与本规程不一致的，以本规程为准。
