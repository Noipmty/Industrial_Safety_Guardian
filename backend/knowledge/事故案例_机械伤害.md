# 某机械制造企业冲压车间机械伤害事故

## 一、事故概况

某年4月12日10时18分，某机械制造企业冲压车间发生一起机械伤害事故，一名冲压操作工在J23-80型开式可倾压力机上调试模具时，违反规程将头部和手臂伸入滑块与工作台之间清理废料，压力机滑块意外下行，将其右手臂和头部挤压，经送医抢救无效死亡。事故直接经济损失约118万元，属于一般生产安全责任事故。

事发企业为某汽车零部件制造公司，主要生产汽车覆盖件冲压件，冲压车间共有各类压力机46台，实行两班制生产。涉事压力机由某老旧设备改造而来，加装了双手启动按钮和光电保护装置，但事发时光电保护装置处于失效状态。

## 二、事故经过

4月12日8时，冲压车间早班开机生产。操作工陈某（男，36岁，冲压工，工龄5年）负责5号压力机生产汽车支架零件。9时许，该设备出现连续两件废料（料片卡在凹模上）的质量问题，陈某报告班组长刘某，刘某安排其调整模具间隙。

10时许，陈某在生产间隙进行模具调试。按规程，清理卡料和调试模具必须停机断电、挂"禁止合闸"警示牌，并将滑块滑至下死点以下或使用安全撑杆支撑。陈某当时认为"只是快速清理一下"，仅按下了停止按钮，未切断主电机电源、未挂牌，也未使用安全撑杆，便将手臂伸入模具区域，用手和压缩空气枪清理凹模内的废料。

10时18分，因主电机电源未断，压力机的自动连续冲压功能仍处于待机状态。同排相邻设备操作工林某误碰了连接在公共气路上的换向阀，或因设备控制回路老化导致的误动作（调查未能完全排除），5号压力机滑块突然下行。陈某躲闪不及，右手臂被挤压在滑块与上模之间，头部同时撞击模具边缘。林某听到呼救后立即按下急停按钮并呼叫救援。

10时20分，车间主任和班组长到达现场，将滑块手动盘车升起，将陈某救出。10时30分，120救护车到达，陈某因颅脑损伤合并失血性休克，经抢救无效于当日13时死亡。

## 三、直接原因分析

1. 陈某严重违反冲压设备安全操作规程，在未停机断电、未挂牌上锁、未使用安全撑杆的情况下，将手臂和头部伸入滑块危险区域清理废料，是事故发生的直接原因；
2. 设备光电保护装置失效后未及时修复，设备"带病运行"，缺少了最后一道防人身的自动保护屏障；
3. 压力机控制回路元器件老化、无独立急停联锁回路的冗余设计，存在意外动作的技术隐患。

## 四、间接与管理原因分析

1. 设备安全设施维护保养不到位。光电保护装置于3月28日被检测出故障，设备部门仅在点检表上做了记录，未列入维修计划跟踪修复，设备带故障运行达15天；
2. 停机挂牌上锁（LOTO）制度未建立。企业没有设备检修断电、验电、挂牌、上锁的刚性程序，员工清理卡料、调试模具等危险作业凭经验、凭习惯操作；
3. 安全教育培训针对性不足。陈某虽有多年的冲压操作经验，但企业培训以应付检查的通用课件为主，缺乏冲压危险区作业、异常情况处置等专项训练，员工对"快速清理一下"的危险性认识不足；
4. 现场安全管理松弛。班组长默许工人图省事不停机清理卡料的习惯性违章行为长期存在，车间未开展反习惯性违章的专项治理；
5. 设备本质安全水平低。老旧压力机改造时未按标准同步完善双手同步启动、滑块制动监测、防意外再启动等安全功能，设备安全投入欠账较多；
6. 隐患排查治理不深不实，把"有故障记录"当成了"整改闭环"，对失效安全装置的停机处理和复检缺乏硬性规定。

## 五、责任追究与处理结果

依据《中华人民共和国安全生产法》《生产安全事故报告和调查处理条例》等法律法规，事故调查组认定该起事故是一起生产安全责任事故，处理结果如下：

1. 操作工陈某违章作业，对事故发生负有直接责任，鉴于其已在事故中死亡，不再追究责任；
2. 班组长刘某对习惯性违章失管失察，给予撤职处分并处罚款；车间主任对设备带病运行和现场违章失察，给予记大过处分并处罚款；
3. 设备动力部门负责人对光电保护装置故障未及时修复负有直接管理责任，给予降职处分并处罚款；
4. 企业分管设备、安全的副总经理履职不力，给予记过处分并处罚款；
5. 企业主要负责人未有效履行安全生产职责，被处罚款并责令作出书面检查；
6. 企业被处以罚款35万元，责令限期整改；对老旧冲压设备开展专项安全评估，未通过评估的设备一律停产整改。

## 六、防范与整改措施

1. 立即建立并严格执行停机挂牌上锁（LOTO）制度。凡进入设备危险区域进行清理、调试、维修、加油等作业，必须执行停机、断电、验电、挂牌、上锁、试运转确认程序，配置专用安全撑杆和锁具，严禁图省事冒险作业；
2. 对全厂压力机光电保护、双手启动、急停、制动监测等安全装置开展专项检查，逐一测试确认，失效的一律停用修复，恢复后经复检合格方可投用；建立安全装置故障强制停机制度，杜绝带病运行；
3. 对老旧压力机实施本质安全化改造，按GB 5083、GB/T 8176等标准完善安全防护功能，改造前进行专项风险评估并制定临时管控措施；
4. 开展冲压行业典型事故案例警示教育，组织全员进行危险区作业、异常处置的实操培训和考核，纠正"快速清理""顺手操作"等侥幸心理；
5. 强化班组安全管理和反习惯性违章治理，将不停机清理卡料、跨越设备、拆除防护等行为列为"零容忍"红线，违者待岗培训；
6. 完善隐患排查治理闭环机制，安全装置故障记录必须转化为维修工单，明确责任人、完成时限和复检确认环节；
7. 合理安排生产节拍和人员轮换，减少连续冲压作业引起的疲劳和注意力下降，从人机工程角度降低操作差错概率。

## 八、事故链复盘与法规链接

### 一、事故链复盘

本起事故的事故链可概括为：设备安全装置故障未修复（防护失效）→ 双手按钮被捆扎、光电被屏蔽（防线被拆除）→ 无停机挂牌上锁制度（制度缺失）→ 员工习惯性冒险作业（行为失控）→ 滑块意外下行 → 伤害发生。机械安全的核心是保持"物理防线"完整，任何对安全装置的屏蔽、拆除、捆扎行为，都是在为事故开门。

### 二、法规标准链接

1. 《中华人民共和国安全生产法》第三十六条：安全设备的设计、制造、安装、使用、检测、维修、改造和报废，应当符合国家标准或者行业标准；生产经营单位必须对安全设备进行经常性维护、保养，并定期检测，保证正常运转；
2. GB 5083《生产设备安全卫生设计总则》、GB/T 8176《冲压车间安全生产通则》关于冲压设备安全防护的要求；
3. GB 28526《机械安全 安全控制系统》关于安全控制系统功能安全的要求；
4. 《用人单位劳动防护用品管理规范》关于个体防护装备配备和使用管理的要求。

### 三、同类事故多发环节自查清单

1. 压力机光电保护、双手启动、急停、制动监测等安全装置是否每日点检并试验有效；
2. 清理卡料、调模、润滑等进入危险区的作业是否严格执行停机断电挂牌上锁；
3. 是否存在用胶带捆扎按钮、短接联锁回路、拆除防护罩等行为；
4. 设备异常征兆（异响、误动作、卡模）是否纳入强制报修和停机评估条件；
5. 新员工和转岗员工是否经过冲压作业专项实操培训并考核合格。

### 四、安全管理提升要点

1. 建立设备安全防护装置清单，逐台设备明确应配置的安全装置、点检标准和失效处置流程，作为设备验收、改造和检查的统一依据；
2. 推行危险区域"一键停机"按钮和门禁联锁，进入冲压危险区必须先停机、再开门，从技术上防止人员与设备动作交叉；
3. 对计件工资制度开展安全审计，在单价结算中嵌入安全质量系数，杜绝"多干多得"诱发冒险作业；
4. 每月开展一次习惯性违章专项观察活动，由班组长对同岗位作业实施行为安全观察，现场纠正并记录，纳入班组考核；
5. 建立老旧设备更新改造滚动计划，对服役超过十年的高风险设备逐年开展安全评估，评估不合格的限期改造或淘汰。

## 九、事故教训与警示

1. "停机挂牌"是保命程序而不是繁琐手续。机械伤害事故中，绝大多数都发生在"只是快速操作一下"的侥幸瞬间，必须通过制度、锁具和反复训练，把"伸手必先断电"变成肌肉记忆；
2. 安全装置失效就是危险区敞开。光电保护、急停装置一旦失效，设备与操作者之间就失去了最后屏障，企业必须建立安全装置故障强制停机制度，宁可停线，不可带病运行；
3. 习惯性违章是慢性毒药。多年的"经验"掩盖了风险，班组长和管理者的默许就是纵容，反违章必须从管理层抓起、从班前会抓起；
4. 老旧设备改造不能只改造生产能力，必须同步评估和补齐安全功能，本质安全化投入是最经济的保险；
5. 机械伤害防范要坚持"管设备、管行为、管环境"三管齐下：设备有防护、行为有约束、环境有秩序，才能实现长治久安；
6. 本案例暴露的"设备缺陷＋程序缺失＋行为冒险"三重叠加模式，在冲压、剪切、机械加工等行业具有普遍性，各车间应结合本岗位设备特点绘制本岗位的事故链图，明确每道防线的责任人，并纳入班前会学习材料。
