# 某制造企业检修作业触电事故

## 一、事故概况

某年8月21日16时05分，某制造企业动力车间在处理车间配电室照明线路故障过程中，一名电工在未停电、未验电、未挂牌的情况下带电作业，身体触及380伏带电裸露接头，发生触电事故，经抢救无效死亡。事故直接经济损失约105万元，属于一般生产安全责任事故。

事发企业为某食品加工企业，厂区建有10千伏配电室一座、低压配电室三座。8月下旬企业处于生产旺季，电气设备连续运行，配电室部分老化线路故障频发。企业仅有持证电工3人，均为从业15年以上的老电工，日常检修任务繁重。

## 二、事故经过

8月21日14时，动力车间值班电工郑某（男，48岁，持低压电工作业证）接到车间报修单，反映2号厂房包装车间照明线路跳闸，部分区域断电。郑某凭多年经验判断为照明回路漏电跳闸，准备直接到配电室处理。

15时30分，郑某与同班组电工赵某到达低压配电室。两人商定由郑某查找故障点、赵某负责递送工具。郑某打开照明回路配电柜，在未办理电气作业票、未通知车间停电、未使用验电器验电、未悬挂"禁止合闸、有人工作"标示牌的情况下，准备用绝缘胶带包扎他判断为故障点的照明回路导线接头。

15时50分，郑某发现该回路一段电缆接头绝缘老化烧蚀，决定更换接线端子。他没有执行停电程序，认为"这个回路已经跳闸没电了"，便徒手拆除烧蚀端子。事实上，该回路跳闸后，车间另一名维修工为赶生产进度，已于15时20分私自合闸送电恢复照明。

16时05分，郑某右手触及带电的相线接头，380伏电压使其右手发生肌肉痉挛性收缩而无法摆脱，身体通过左手和双脚形成放电回路，触电倒地。赵某当时背身整理工具，几秒钟后发现郑某倒地抽搐，随即大声呼救并拉下配电柜总开关切断电源。

16时07分，闻讯赶到的员工将郑某移开带电体并开展心肺复苏。16时15分，120救护车到达，持续抢救40分钟后，郑某因心室颤动导致的心搏骤停，经抢救无效死亡。事后查明，该照明回路保护用熔断器额定电流偏大且安装了不合格的替代熔丝，未能有效动作切断短路电流，扩大了电击伤害。

## 三、直接原因分析

1. 郑某严重违反电气作业安全规程，在未办理作业票、未停电、未验电、未挂牌、未装设接地线的情况下进行带电作业，且未戴绝缘手套，徒手触碰导线接头，是事故发生的直接原因；
2. 车间维修工未经批准擅自恢复送电，在有人作业的回路上合闸且未通知、未确认，直接造成作业面带电；
3. 回路保护熔断器配置不当、熔丝规格不符，故障时不能可靠切断电流，延长了触电时间和伤害程度。

## 四、间接与管理原因分析

1. 电气作业许可和操作票制度执行不严。企业虽有电气作业管理规定，但实际作业中长期"口头安排、直接动手"，作业票、停电验电挂牌程序形同虚设；
2. 无"谁合闸、谁负责"的送电审批控制。跳闸回路恢复送电无审批、无告知、无确认，任何人员都可以随意合闸，作业安全完全依赖他人"碰巧不知道"；
3. 安全工器具管理缺失。配电室未按规程配备验电器、绝缘手套、绝缘垫等安全工器具，或配备后超期未检，郑某作业时根本未使用；
4. 老电工经验主义倾向突出。郑某凭"经验判断没电"取代验电确认，暴露出企业安全教育重形式、轻实效，老员工的习惯性违章长期未纠正；
5. 设备隐患排查不到位。电缆接头老化烧蚀、熔断器配置错误等隐患长期存在未被发现和整改；
6. 生产任务与检修安全冲突时缺乏统筹。生产旺季"边生产边抢修"成为常态，管理层默认"不停电快修"，助长了违章作业风气。

## 五、责任追究与处理结果

依据《中华人民共和国安全生产法》《生产安全事故报告和调查处理条例》等法律法规，事故调查组认定该起事故是一起生产安全责任事故，处理结果如下：

1. 郑某违章带电作业，对事故发生负有直接责任，鉴于其已在事故中死亡，不再追究责任；
2. 车间维修工擅自合闸送电，对事故发生负有直接责任，给予开除处分，并移送司法机关审查是否构成犯罪；
3. 动力车间主任对电气作业管理失控负有直接管理责任，给予撤职处分并处罚款；
4. 企业设备安全管理部门负责人和分管副总对工器具配备、隐患整改失察，分别给予记过处分并处罚款；
5. 企业主要负责人未依法履行安全生产管理职责，被处罚款；
6. 企业被处以罚款30万元，责令停产整顿15天，全面整顿电气作业安全管理制度。

## 六、防范与整改措施

1. 立即修订并刚性执行电气作业管理制度。电气检修必须办理电气作业票，严格执行停电、验电、放电、装设接地线、悬挂标示牌和装设遮栏（围栏）等保证安全的技术措施，以及工作票、工作许可、工作监护、工作间断和终结等保证安全的组织措施；
2. 建立"谁挂牌、谁摘牌""谁合闸、谁负责"制度，恢复送电必须由挂牌人确认后执行，跳闸回路送电须经电气值班负责人批准并通知相关区域；
3. 全面清理配备和检测安全工器具。按规程配齐低压验电器、绝缘手套、绝缘鞋、绝缘垫、接地线等，建立台账，按周期试验，不合格立即报废更新；
4. 对全厂配电系统开展专项检查，重点排查线路老化、接头过热、保护定值不当、熔丝替代等隐患，逐项落实整改；
5. 开展电气安全专项培训，组织全员特别是电工学习触电事故案例，纠正"凭经验、不走程序"的错误观念，将"先验电、后作业""不验电、不伸手"作为铁律；
6. 严禁非持证人员和非电气专业人员从事电气操作，严禁任何人擅自合闸送电；
7. 统筹生产与检修计划，坚决纠正"边生产边抢修""不停电快修"的错误做法，检修安全条件不落实一律不得开工。

## 八、事故链复盘与法规链接

### 一、事故链复盘

本起事故的事故链可概括为：线路老化跳闸（隐患存在）→ 未查明原因反复送电（隐患放任）→ 维修工擅自合闸（送电失控）→ 电工不停电不验电不挂牌（程序失效）→ 徒手触碰接头（最后防线失守）→ 触电死亡 → 保护装置配置错误扩大伤害。电气作业"停电、验电、挂牌"三项程序全部缺失，叠加"送电无管控"，构成典型的管理性触电事故。

### 二、法规标准链接

1. 《中华人民共和国安全生产法》第三十六条关于安全设备管理、第四十一条关于作业安全管理的规定；
2. GB/T 13869《用电安全导则》关于一般用电安全的基本要求；
3. GB 26860《电力安全工作规程 发电厂和变电站电气部分》关于停电、验电、接地、悬挂标示牌和装设遮栏等保证安全的技术措施要求；
4. GB/T 3787《手持式电动工具的管理、使用、检查和维修安全技术规程》；
5. GB 50054《低压配电设计规范》关于保护电器配置的要求。

### 三、同类事故多发环节自查清单

1. 电气检修是否做到百分之百办票、百分之百验电、百分之百挂牌上锁；
2. 跳闸回路恢复送电是否履行审批和通知程序，是否存在任何人可随意合闸的情况；
3. 验电器、绝缘手套、绝缘垫等安全工器具是否齐全、按期试验、正确使用；
4. 保护电器定值和熔丝规格是否与线路设备匹配，是否存在铜丝代替熔丝现象；
5. 配电室和检修集中区域是否配置急救箱和自动体外除颤器，员工是否掌握心肺复苏技能。

### 四、电气安全管理提升要点

1. 建立"一柜一图一档"：每面配电柜标注单线系统图、保护定值和管理责任人，建立设备台账和缺陷记录，实现闭环销号；
2. 推行停送电联锁管理，检修回路电源开关加装专用锁具，钥匙由挂牌人和值班电工双人持有，任何送电必须双确认；
3. 每年雨季前组织全厂电气预防性试验，检测线路绝缘电阻、接地电阻和保护装置动作特性，试验报告存档备查；
4. 组织电工岗位技能比武和事故案例警示教育，把"停电必验电、送电必审批"纳入年度安全承诺内容；
5. 与有资质的电力技术服务机构建立常年合作关系，弥补企业内部电气技术力量不足，复杂故障处理和年度试验委托专业机构实施。

## 九、事故教训与警示

1. 电工作业"三大纪律"——停电、验电、挂牌，一条都不能省。再老练的电工也不能用"经验判断"代替"仪器验证"，验电只需几秒钟，省下的几秒钟可能就是一条命；
2. 送电失控比停电作业更可怕。检修者再规范，也防不住他人随意合闸，必须用制度、锁具、标示牌把送电权限管起来，实现检修与送电的物理隔离和程序隔离；
3. 保护电器配置不是小事。熔断器、断路器的定值和规格必须与线路和设备匹配，错误的保护装置会在关键时刻失效，放大事故后果；
4. 生产与安全发生冲突时，必须无条件为安全让路。"赶进度不停电""老电工不用验"这类做法，是在用生命赌概率；
5. 触电抢救的黄金时间极短，企业应组织员工普遍学习心肺复苏和AED使用技能，完善配电室应急照明、报警和救援通道，确保一旦发生意外能够第一时间有效施救；
6. 企业应将本案例编制成警示教育课件，纳入电工年度复训必学内容，并在配电室、检修现场张贴"停电、验电、挂牌"三步法提示牌，让每一名电气作业人员在伸手之前先自问一句：真的没电吗？
