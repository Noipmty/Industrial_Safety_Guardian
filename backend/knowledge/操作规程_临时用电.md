# 临时用电作业安全操作规程

## 第一章 编制目的与适用范围

### 一、编制目的

为规范公司临时用电的安全管理，防止触电、电气火灾等事故的发生，保障人员生命和财产安全，依据《中华人民共和国安全生产法》《中华人民共和国电力法》及JGJ 46《施工现场临时用电安全技术规范》、GB/T 13869《用电安全导则》等法律法规和标准规范，结合公司实际，制定本规程。

### 二、适用范围

本规程适用于公司区域内所有临时性用电作业及临时用电设施的管理，包括：

1. 检修、施工、抢险等作业中临时敷设的低压配电线路和用电设备；
2. 临时搭建的工地、库房、办公场所的用电设施；
3. 移动式、手持式电动工具的使用；
4. 临时电源箱、插排、电缆的使用管理。

正式建设的供配电工程按国家和行业相关标准执行，不适用本规程。临时用电期限一般不超过三个月，超过期限的应办理正式用电手续或申请延期。

## 第二章 危险有害因素分析

### 一、触电危险

1. 直接接触触电：误触裸露带电体、带电检修、无证操作电气设备；
2. 间接接触触电：设备外壳漏电且未可靠接地、漏电保护器缺失或失效；
3. 环境因素触电：潮湿、金属容器内、雨天作业等高危环境中电气绝缘性能下降，安全电压和双重绝缘要求未落实；
4. 手持电动工具绝缘破损、电缆拖地泡水、接头裸露等造成触电。

### 二、电气火灾及其他危险

1. 线路超负荷运行、接头松动打火、绝缘老化短路引发电气火灾；
2. 电弧、电火花引燃周边可燃气体、粉尘、纤维引发燃爆；
3. 临时线路私拉乱接、就近缠绕在金属构件上、跨越通道被车辆碾压损坏；
4. 误送电、误合闸造成检修人员触电或设备损坏；
5. 电气设备故障引发的高温灼烫和熔融金属飞溅伤害。

## 第三章 作业前准备

### 一、资格与审批

1. 临时用电的安装、维修、拆除必须由持有效电工作业操作证的电工实施，严禁无证人员从事电气作业；
2. 临时用电实行审批制度，使用单位应填报临时用电申请，注明用电地点、容量、期限、用途和防护措施，经属地单位和安全管理部门审批后实施；容量较大或涉及高压的，报设备动力部门审批；
3. 临时用电设施安装完毕后，应经申请单位、安装电工和审批部门共同检查验收，确认合格并办理验收手续后方可送电使用。

### 二、方案与技术要求确认

1. 用电容量5千瓦以上或使用时间较长的临时用电，应编制临时用电方案，确定负荷计算、线路走向、配电方式和接地系统；
2. 临时用电系统应采用TN-S接零保护系统，实行三级配电、两级漏电保护，做到"一机、一闸、一漏、一箱"，严禁一闸多机；
3. 漏电保护器参数应匹配：一般场所末级漏电保护器额定动作电流不大于30毫安、动作时间不大于0.1秒；潮湿和有腐蚀介质场所应不大于15毫安；
4. 爆炸危险环境内的临时用电设备、灯具、开关应为防爆型，其级别、组别应与环境要求一致。

## 第四章 作业步骤与安全要点

### 一、线路敷设安全要点

1. 临时电缆宜架空敷设或沿地面敷设，架空敷设时应采用绝缘子固定，严禁直接绑扎在金属脚手架、管道、栏杆上；沿地面敷设时应穿管保护，避免穿越作业通道和车辆道路，无法避免的应采取过路保护措施；
2. 电缆接头应牢固可靠并做好绝缘包扎，禁止将电缆接头浸泡在水中或敷设在易受机械损伤的部位；
3. 禁止使用花线、绝缘破损的电缆和伪劣插排，禁止多台设备共用一个插排超负荷用电；
4. 临时配电箱应防雨、防尘、上锁管理，箱内开关电器完好、标识清晰，进出线口应固定在箱体下侧。

### 二、用电作业安全要点

1. 电气设备停电检修应执行停电、验电、装设接地线、悬挂标示牌和装设遮栏的安全技术措施，并在电源开关处上锁挂牌，实行"谁挂牌、谁摘牌"；
2. 检修完毕恢复送电前，应确认人员全部撤离、工具材料已清理、接地线已拆除，由挂牌人亲自摘牌送电；
3. 手持电动工具使用前应检查外壳、手柄、电缆、插头及保护接零是否完好，一般场所选用Ⅱ类工具，潮湿场所或金属构架内作业应选用Ⅲ类工具或装设额定动作电流不大于15毫安的漏电保护器；
4. 在金属容器、管道内和潮湿狭小空间使用照明和电动工具时，照明电压不大于12伏，并设专人在外监护；
5. 电气设备着火时，应先切断电源，使用干粉、二氧化碳灭火器扑救，严禁使用水、泡沫灭火器带电扑救。

### 三、使用与维护管理

1. 用电单位应指定专人负责临时用电设施的日常检查维护，每日检查漏电保护器试验按钮动作是否可靠；
2. 检查发现电缆破损、接头松动、开关失灵等隐患，应立即停电处理，严禁带故障运行；
3. 临时用电到期或作业结束后，使用单位应及时通知电工拆除临时线路和设备，恢复现场，办理注销手续；
4. 任何单位和个人不得擅自接引电源、增容和变更用电地点，确需变更的应重新办理审批手续。

## 第五章 个人防护装备要求

1. 电工作业时应穿长袖工作服、绝缘鞋，戴绝缘手套，使用合格的验电器、绝缘棒、绝缘垫等安全工器具；
2. 安全工器具应定期试验并在有效期内使用，绝缘手套、绝缘鞋使用前应进行外观检查，发现破损、发粘、裂纹的禁止使用；
3. 高处电气作业应系挂安全带，传递工具材料应使用绳索，禁止上下抛掷；
4. 在潮湿环境和金属容器内作业时，应选用双重绝缘工具并配备漏电保护器，必要时应站在绝缘垫或干燥木板上作业；
5. 雷雨天气禁止进行露天电气作业和倒闸操作。

## 第六章 应急处置措施

### 一、触电急救

1. 发现人员触电，救护人员应迅速使触电者脱离电源：立即拉开电源开关或拔掉插头；无法立即断电时，应使用干燥木棒、绝缘杆等绝缘物挑开电线，或戴绝缘手套拉拽触电者干燥衣物；
2. 触电者未脱离电源前，救护人员严禁直接用手触碰其身体，防止连环触电；
3. 脱离电源后，将触电者移至通风处平躺，解开衣领，检查意识和呼吸；呼吸心跳停止的，立即进行心肺复苏，坚持不间断抢救直至专业医护人员到达；
4. 触电者神志清醒但有电击伤创面的，用干净敷料包扎后送医；高处触电坠落者应防止二次伤害，妥善固定搬运。

### 二、电气火灾处置

1. 发现电气设备着火，应首先切断电源，并向配电室和应急值班室报告；
2. 无法立即断电时，使用干粉灭火器、二氧化碳灭火器带电扑救，保持安全距离，严禁使用水或泡沫灭火器；
3. 火势较大无法控制时，立即撤离人员、拨打119报警，并启动公司火灾应急预案；
4. 灭火后不得立即送电，应查明原因、排除故障并经检查确认后方可恢复供电。

### 三、停电事故处置

1. 突发停电时应关闭用电设备开关，防止来电时设备突然启动造成伤害；
2. 涉及工艺安全的场合，按应急预案执行安全停车程序；
3. 查明停电原因，排除故障后按规定程序恢复送电。

## 第七章 相关法规标准与要点提示

1. 主要法规标准依据：《中华人民共和国安全生产法》第四十一条关于安全设备管理的规定；JGJ 46《施工现场临时用电安全技术规范》；GB/T 13869《用电安全导则》；GB 50194《建设工程施工现场供用电安全规范》；GB/T 3787《手持式电动工具的管理、使用、检查和维修安全技术规程》。
2. 安全电压使用速查：一般场所行灯电压不大于36伏；潮湿和易触及带电体场所不大于24伏；特别潮湿场所、金属容器和管道内作业不大于12伏。
3. 漏电保护器配置速查：末级保护额定动作电流一般场所不大于30毫安、动作时间不大于0.1秒；潮湿、有腐蚀介质场所不大于15毫安；总保护按系统设计整定，实现分级保护、上下级配合动作。
4. 手持电动工具分类管理：Ⅰ类工具必须可靠接地（接零）并配漏电保护；Ⅱ类工具（双重绝缘）适用于一般场所；Ⅲ类工具（安全电压）适用于潮湿、金属容器等高危场所；使用前检查外壳、电缆、插头完好，检查记录保存备查。
5. 临时用电档案要求：审批申请、安装验收记录、日常巡检记录、漏电保护器测试记录、拆除注销手续应形成完整档案，保存至用电结束后一年以上，随时可查证。
6. 管理提示：夏季用电高峰和雨季前，应组织电气专业人员对临时用电系统开展专项测试，重点测量接地电阻、绝缘电阻和漏电保护器动作特性，测试记录纳入隐患排查台账；临时用电设施附近进行动火作业时，应事先确认电缆走向，防止火花引燃电缆绝缘层。
7. 本规程未尽事宜，按国家现行标准规范及公司相关制度执行。

## 第八章 附则

1. 本规程由公司安全管理部门负责解释和修订；
2. 各单位应组织相关员工学习本规程并考核，电工、焊工等特种作业人员应持证上岗；
3. 违反本规程私拉乱接电源、违章用电的，按公司安全生产奖惩制度严肃处理；
4. 本规程自发布之日起施行；
5. 各车间（单位）应结合本规程编制临时用电现场检查表，明确检查项目、判定标准和整改要求，作为日常巡检、专项检查和季节性检查的统一依据，检查记录按月归档；对检查中发现的共性问题，每季度组织一次专题分析并落实源头改进措施。
