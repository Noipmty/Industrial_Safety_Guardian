# 某化工企业液氨球罐区管线泄漏事故

## 一、事故概况

某年7月18日14时26分，某化工企业液氨罐区在实施倒罐作业过程中，液氨输送管线与球罐连接处法兰垫片刺漏，导致液氨大量泄漏并快速汽化扩散，形成有毒气体云团。事故共造成4名现场作业及巡检人员中毒死亡，12名员工和周边群众中毒受伤住院治疗，其中3人重伤；厂区东侧部分农作物和绿化植被受损，周边约600名群众紧急疏散。事故直接经济损失约860万元，属于较大生产安全责任事故。

事发企业为某精细化工公司，主要产品为合成氨、尿素及下游化工产品，液氨罐区建有2座400立方米球罐、2座1000立方米卧式储罐，最大储存量约2400吨，构成一级重大危险源。事故发生前，企业正处于夏季高温生产负荷调整期。

## 二、事故经过

7月18日上午，企业因下游装置减负荷运行，调度安排将1号球罐（液位约85%）中的液氨倒至3号卧式储罐，以腾出球罐容量接收后续批次产品。11时30分，储运车间主任安排操作班长张某带领操作工王某、李某实施倒罐作业，同时通知设备维修班对2号球罐液位计进行检修。

13时40分，张某、王某到达现场，按流程开启1号球罐底部出料阀和液氨管线相关阀门，倒罐作业开始，管线压力约1.35兆帕。13时55分，李某巡检至罐区时，发现液氨管线与1号球罐连接法兰处有白色雾状气体冒出，并伴有强烈刺激性气味，随即呼喊附近人员撤离并上报。

14时02分至14时20分，泄漏量迅速增大，白色雾团沿地面快速扩散至罐区围墙外。张某在关闭靠近泄漏点的根部阀门时，因吸入高浓度氨气倒地；王某、李某在撤离过程中中毒倒于罐区通道。企业立即启动应急预案，组织佩戴正压式空气呼吸器的抢险人员进入现场，14时26分实施喷水稀释、封堵泄漏法兰周边区域，并关闭上下游切断阀。

14时50分，企业向当地应急管理部门报告，并通知周边村庄组织疏散。15时40分，专业救援力量到场，使用雾状水幕压制氨气扩散，对泄漏法兰实施带压堵漏。18时10分，泄漏点被封堵，倒罐流程停用。事故造成张某、王某、李某及一名前来救援的消防岗位人员共4人经抢救无效死亡。环境监测显示，氨气主要影响厂界东侧500米范围，未对更远区域和水源造成显著影响。

## 三、直接原因分析

经现场勘查、技术鉴定和调查取证，事故直接原因为：

1. 泄漏法兰使用的垫片选型错误。1号球罐出料管线法兰原设计应采用金属缠绕垫片，维修时被错误更换为普通非金属垫片，该垫片不耐低温和渗透，在液氨低温、高压工况下发生材质劣化和刺漏；
2. 倒罐作业前未对管线连接部位进行压力试验和气密性确认，开阀升压后法兰密封面即出现泄漏，操作人员又贸然靠近泄漏点关闭根部阀，缺乏最基本的个体防护和处置常识；
3. 罐区固定式氨气泄漏检测报警系统自5月起处于故障停用状态，报警探头被拆除送检后未及时复位，导致泄漏初期无法自动报警，延误了发现和处置时机。

## 四、间接与管理原因分析

1. 检维修管理失控。2号球罐液位计检修和垫片更换作业未办理检修作业票，未执行检修交出确认程序，更换后的垫片未经技术确认和质量验收即投用；
2. 特殊作业和变更管理缺失。垫片材质变更属于设备设施变更，未按变更管理制度履行审批手续，变更风险辨识和告知完全缺位；
3. 安全仪表和监测设施管理形同虚设。可燃有毒气体检测报警系统故障后长期未修复，未纳入隐患管理，交接班记录中无相应记载，安全管理部门检查中多次发现但未跟踪闭环；
4. 应急处置能力不足。岗位人员对氨气泄漏的应急处置程序掌握不熟练，未佩戴任何呼吸防护器材就冒险进入泄漏区关阀，暴露出日常应急培训流于形式；罐区风向标、正压式空气呼吸器配置点设置不合理；
5. 安全生产责任制落实不到位。企业主要负责人对重大危险源管理重视不够，专职安全管理人员配备不足，对承包商和内部检维修队伍的监督检查缺位；
6. 地方监管部门曾对企业开展专项检查并指出罐区仪表失灵问题，企业整改不彻底，隐患整改闭环管理机制失效。

## 五、责任追究与处理结果

依据《中华人民共和国安全生产法》《生产安全事故报告和调查处理条例》等法律法规，事故调查组认定该起事故是一起生产安全责任事故，有关责任单位和人员处理如下：

1. 企业总经理作为主要负责人，未依法履行安全生产管理职责，对事故负有主要领导责任，由应急管理部门依法处以上一年度年收入40%的罚款，并被追究相应刑事责任；
2. 分管生产副总、储运车间主任对检维修作业组织管理和隐患整改督办不力，负有直接管理责任，分别给予撤职处分并处罚款；
3. 设备维修班班长违规更换垫片、未履行作业票程序，对事故发生负有直接责任，移送司法机关依法追究刑事责任；
4. 当班操作班长张某、操作工王某已在事故中死亡，不再追究责任；
5. 企业被处以法定上限罚款，责令停产整顿3个月，重大危险源备案被重新核查，向监管部门作出深刻检查；
6. 对负有监管职责的相关部门3名工作人员给予政务处分。

## 六、防范与整改措施

1. 全面开展设备设施完整性排查。对全厂压力管道、法兰、垫片、阀门逐台核对台账与实物，重点排查垫片选型与工况匹配性，建立备件材质复核确认制度，杜绝错用、混用；
2. 严格落实检维修作业许可制度。所有检维修作业必须办理作业票，明确交出条件、隔离措施、质量验收环节，未经验收合格不得投料开车；
3. 强化变更管理。凡涉及设备、材质、工艺参数、操作程序的变更，必须履行变更申请、风险评估、审批和告知程序，变更资料归档；
4. 立即恢复并升级安全监测系统。可燃有毒气体检测报警系统实行专责管理，建立报警系统运行台账，报警信息与中央控制室联动，探头定期校验，严禁擅自停用；
5. 强化重大危险源管控。完善罐区应急切断、水幕喷淋、围堰和防扩散设施，落实在线监测、巡检和包保责任制；
6. 提升应急处置能力。修订氨泄漏专项预案和现场处置方案，每季度组织实战演练，配足正压式空气呼吸器和堵漏器材，开展岗位人员"一点课、一演练"训练，严禁未佩戴防护器材进入泄漏区域；
7. 健全隐患排查治理闭环机制，对监管部门提出的问题实行整改责任、措施、资金、时限、预案"五落实"。

## 八、事故链复盘与法规链接

### 一、事故链复盘

本起事故的事故链可概括为：垫片选型错误（技术缺陷）→ 检修无票作业（程序失效）→ 变更未评估审批（管理漏洞）→ 报警系统故障停用（监测失效）→ 泄漏后无防护冒险关阀（应急失当）→ 伤亡扩大。六道防线环环失守，只要任何一道防线有效，事故就不会发生或不会造成人员死亡。企业应组织全员学习事故链复盘方法，对照本岗位查找"下一道可能失守的防线"。

### 二、法规标准链接

1. 《中华人民共和国安全生产法》第四十一条：生产经营单位应当安全使用设备设施，组织开展危险源辨识和评估，落实监控措施；
2. 《危险化学品安全管理条例》第十五条、第二十条关于危化品生产储存装置安全管理的要求；
3. GB 30871-2022《危险化学品企业特殊作业安全规范》关于动火、检维修作业的管理要求；
4. TSG D0001《压力管道安全技术监察规程 工业管道》关于管道元件选用、安装和定期检验的规定；
5. GB 50493《石油化工可燃气体和有毒气体检测报警设计标准》关于检测报警系统设置与维护的要求。

### 三、同类事故多发环节自查清单

1. 检维修后首次投用是否经过压力试验和气密性确认；
2. 备品备件材质是否与设计工况一致，是否经过技术确认和验收；
3. 可燃有毒气体报警系统是否存在故障未修复、擅自停用的情况；
4. 岗位人员是否熟练掌握泄漏应急处置卡，是否配备并会正确使用正压式空气呼吸器；
5. 重大危险源包保责任人是否按期到点检查并如实记录。

## 九、事故教训与警示

这起事故再次警示我们：危化品企业任何一个微小的设备缺陷，叠加失控的管理漏洞，都可能酿成群死群伤的重大事故。本案例的核心教训在于：

1. "小垫片"背后是"大管理"。垫片错用是表象，检维修无票作业、变更无审批、验收走过场才是根源，企业必须把设备完整性管理和特殊作业许可作为不可逾越的红线；
2. 安全监测设施"带病运行"等于埋雷。报警系统故障停用近两个月无人过问，反映出隐患整改闭环机制的全面失效，任何安全设施停用都必须履行审批、告知和临时补偿措施；
3. 盲目冒险处置是伤亡扩大的直接推手。三名员工未戴防护器材进入泄漏区，教训极为惨痛，必须通过反复演练让"先防护、再处置""不防护、不进入"成为条件反射；
4. 重大危险源企业必须严格落实包保责任制，主要负责人、技术负责人、操作负责人层层压实责任，接受政府和社会监督，坚决防止重特大事故发生；
5. 建议将本案例改编为岗位情景演练脚本，每半年在罐区组织一次氨泄漏"无脚本"拉动演练，检验报警响应、人员疏散、工艺切断、带压堵漏和伤员救治全流程的真实能力，演练评估结果纳入车间季度考核。
