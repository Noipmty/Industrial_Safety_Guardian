# 安全教育培训制度

## 第一章 总则

### 一、编制目的

为规范公司安全教育培训工作，提高全体从业人员的安全意识和安全技能，保证教育培训的计划性、针对性和实效性，从源头上防范和减少"三违"行为，依据《中华人民共和国安全生产法》《生产经营单位安全培训规定》（原国家安监总局令第3号，经修订）及《安全生产培训管理办法》等法律法规和规章，结合公司实际，制定本制度。

### 二、适用范围

本制度适用于公司全体从业人员的安全教育培训管理，包括公司领导、管理人员、一线员工、劳务派遣人员、实习学生、临时聘用人员，以及对承包商作业人员入场安全教育的管理要求。

### 三、基本原则

1. 先培训、后上岗：未经安全培训合格的从业人员，不得上岗作业；
2. 全员覆盖、突出重点：主要负责人、安全管理人员、特种作业人员、新员工等重点人员依法强制培训，其他人员按规定全员轮训；
3. 理论与实操并重：既讲授安全知识法规，又强化岗位操作技能和应急处置能力训练；
4. 培训与使用挂钩：培训考核结果作为上岗、转岗、晋级和评优的依据。

## 第二章 组织机构与职责

### 一、主要负责人职责

公司主要负责人组织制定并实施本单位安全生产教育和培训计划，保证培训所需经费投入，对培训工作全面负责。

### 二、安全管理部门职责

1. 归口管理安全教育培训工作，编制年度培训计划并组织实施；
2. 建立从业人员安全教育培训档案，实行"一人一档"，如实记录培训时间、内容、参加人员、考核结果等情况；
3. 组织公司级安全教育和主要负责人、安全管理人员、特种作业人员的取证复审管理；
4. 组织培训效果评估，改进培训方式和内容；
5. 对各部门、车间培训落实情况进行监督检查和考核。

### 三、各部门、车间职责

1. 组织实施车间级、班组级安全教育和日常安全活动；
2. 结合岗位风险开展针对性技能训练和事故案例学习；
3. 落实"四新"（新工艺、新技术、新材料、新设备）投用前的专项培训；
4. 确保本部门人员按时参加培训，做好培训记录并报安全管理部门归档。

### 四、人事部门职责

将安全培训纳入员工入职、转岗、晋升的管理流程，未经培训合格不予办理上岗手续；配合安全管理部门做好培训组织和档案管理。

## 第三章 培训对象与培训要求

### 一、主要负责人和安全管理人员

1. 公司主要负责人和安全生产管理人员应当具备与本单位所从事的生产经营活动相应的安全生产知识和管理能力；
2. 属于危险物品生产、经营、储存单位以及矿山、金属冶炼、建筑施工、运输单位的，其主要负责人和安全生产管理人员应当由主管的负有安全生产监督管理职责的部门对其安全生产知识和管理能力考核合格；
3. 主要负责人和安全管理人员按规定每年参加再培训，持续更新知识。

### 二、特种作业人员

1. 电工、焊接与热切割作业、高处作业、制冷作业等特种作业人员，必须按照国家有关规定经专门的安全作业培训，取得相应特种作业操作证后，方可上岗作业；
2. 特种作业操作证按规定周期复审，逾期未复审或复审不合格的，不得继续从事特种作业；
3. 公司建立特种作业人员台账，动态管理证书有效期，提前3个月组织复审报名。

### 三、新入职员工三级安全教育

新员工（含劳务派遣人员、实习学生）上岗前必须经过公司、车间、班组三级安全教育培训，总学时不少于24学时；危险物品等行业新上岗的从业人员培训时间不得少于72学时：

1. 公司级教育：安全生产法律法规、公司安全生产基本情况与规章制度、主要危险因素及防范措施、事故案例、劳动防护用品使用、应急与逃生知识等；
2. 车间级教育：车间生产工艺流程及特点、危险区域与设备状况、车间安全规章制度、劳动纪律、作业场所的危害因素与防护要求、典型事故案例等；
3. 班组级教育：岗位安全操作规程、岗位间工作衔接配合的安全与职业卫生事项、工器具与个体防护用品的使用方法、本岗位事故案例与应急处置、实际操作示范与练习等。

三级教育结束后进行书面或实操考核，考核合格方可独立上岗；考核不合格的，重新培训，重新考核仍不合格的调整岗位或依法解除劳动关系。

### 四、其他人员的培训要求

1. 转岗、复岗人员：离开岗位六个月以上重新上岗，或调整到新岗位的，必须重新接受车间级、班组级安全教育；
2. "四新"教育：采用新工艺、新技术、新材料或使用新设备前，必须对有关人员重新进行有针对性的安全培训，考核合格后方可上岗；
3. 承包商人员：进入公司区域作业前必须接受入场安全教育，内容包括公司安全规定、作业许可制度、现场危险因素、应急处置和禁止事项，经考核合格并登记后方可作业；
4. 来访人员：进入生产区域前接受必要的安全告知。

## 第四章 培训内容与学时

### 一、培训主要内容

1. 安全生产法律法规和标准规范；
2. 公司安全生产规章制度和岗位安全操作规程；
3. 危险有害因素辨识与风险管控知识，事故预防、隐患识别和报告方法；
4. 劳动防护用品的正确佩戴和使用；
5. 消防知识、灭火器材使用和初期火灾扑救；
6. 职业病危害因素与防护措施、职业健康检查要求；
7. 应急预案、现场处置方案和自救互救、急救技能；
8. 典型事故案例分析与警示教育。

### 二、学时要求

1. 新员工三级安全教育总学时按本章第三条规定执行；
2. 全员年度再培训不少于8学时；危险物品生产、储存单位从业人员年度再培训不少于20学时；
3. 车间级培训每季度不少于1次，班组安全活动每周不少于1次；
4. 各类取证、复审培训按国家规定学时执行。

## 第五章 培训实施与管理

### 一、培训方式

采取课堂教学、网络学习、现场示范、实操演练、事故案例讨论、技能比武等多种方式相结合；鼓励开展"师带徒"、岗位练兵和"微课堂"活动，提高培训实效。

### 二、培训考核

1. 培训结束后进行考核，考核可采用笔试、机考、口试或实操等方式，80分（或同等标准）为合格；
2. 考核不合格者允许补考一次，补考不合格的调离岗位重新培训；
3. 特种作业人员理论及实操考核按国家统一标准执行。

### 三、培训档案

1. 建立"一人一档"的从业人员安全教育培训档案，内容包括：个人信息、三级教育记录、历次培训记录、考核成绩、取证复审情况等；
2. 培训档案由安全管理部门统一管理，保存期限不少于三年；
3. 培训组织单位应在培训结束后五个工作日内将签到表、课件、考核记录等资料移交归档。

### 四、效果评估

安全管理部门每年至少组织一次培训效果评估，通过考试抽查、现场提问、行为观察、违章统计和事故分析等手段评估培训成效，据此修订下一年度培训计划。

## 第六章 检查与考核

1. 安全管理部门每月检查各单位培训计划执行情况、记录完整性和人员参加率，纳入月度安全绩效考核；
2. 通过现场抽查提问、随机闭卷测试等方式检验员工实际掌握程度，测试结果与单位考核挂钩；
3. 对未按计划组织培训、培训记录弄虚作假、安排未经培训合格人员上岗的，追究单位负责人和直接责任人责任；
4. 每年年底对全员培训完成率、持证率、考核合格率进行统计通报，未达标的单位取消年度安全评优资格。

## 第七章 奖惩规定

1. 对培训工作组织有力、成效显著的单位和个人，给予通报表扬和奖励；
2. 对在各类安全知识竞赛、技能比武中取得优异成绩的员工，给予表彰奖励；
3. 对无故不参加培训、考核舞弊的员工，给予批评教育、扣减绩效直至待岗处理；
4. 因未组织或未参加规定培训导致人员上岗后发生事故的，依法依规追究相关管理人员责任；
5. 以欺骗、贿赂等不正当手段取得特种作业操作证的，一经发现立即调离特种作业岗位并按公司规定严肃处理。

## 第九章 法规链接与实施要点

1. 主要法规依据：《中华人民共和国安全生产法》第二十八条关于安全教育培训的规定；《生产经营单位安全培训规定》（原国家安监总局令第3号，经修订）关于培训学时、内容和考核的要求；《特种作业人员安全技术培训考核管理规定》关于特种作业人员持证上岗的规定。
2. 学时要求速查：主要负责人和安全管理人员初次培训不少于32学时，每年再培训不少于12学时；新员工三级教育总学时不少于24学时，危险物品等行业不少于72学时；特种作业人员培训按国家统一大纲和学时执行。
3. 档案管理提示：培训档案应做到"培训有计划、实施有签到、内容有课件、考核有试卷、结果有记录、评估有报告"六有标准，随时可查证、可追溯。
4. 常见问题警示：以签字代替培训、以会议代替教育、课件多年不更新、考试人人满分、档案事后补录等，均属于培训造假的典型情形，一经查实从严追责。
5. 实施提示：培训内容应结合岗位风险量身定制，优先采用案例教学、实操演练和线上碎片化学习相结合的方式；每年至少组织一次全员安全知识竞赛或技能比武，以赛促学、以练促用，推动培训成果向岗位行为转化。

## 第十章 附则

1. 本制度由公司安全管理部门负责解释和修订；
2. 各部门、车间可根据本制度制定本单位培训实施细则；
3. 本制度自发布之日起施行，原有规定与本制度不一致的，以本制度为准。
