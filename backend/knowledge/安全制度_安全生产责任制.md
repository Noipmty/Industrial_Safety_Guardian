# 安全生产责任制

## 第一章 总则

### 一、编制目的

为全面落实企业安全生产主体责任，建立"党政同责、一岗双责、齐抓共管、失职追责"和"全员安全生产责任制"的工作格局，明确公司各层级、各岗位的安全生产职责，做到安全生产人人有责、各负其责，依据《中华人民共和国安全生产法》《企业安全生产标准化基本规范》（GB/T 33000）等法律法规和标准，结合公司实际，制定本制度。

### 二、适用范围

本制度适用于公司全体员工，包括公司领导层、各职能部门、各生产车间（分厂）、班组及全体从业人员，以及在公司区域内长期工作的劳务派遣人员、实习人员的管理参照执行。公司通过与每一位员工签订安全生产责任书的方式，将本制度确定的职责落实到岗、到人。

### 三、基本原则

1. 管行业必须管安全、管业务必须管安全、管生产经营必须管安全；
2. 谁主管、谁负责，谁审批、谁负责，谁签字、谁负责；
3. 安全生产实行一票否决制，安全责任考核结果与薪酬、评优、晋升直接挂钩；
4. 责任追究坚持"尽职免责、失职追责"，以职责履行情况作为事故责任认定的基本依据。

## 第二章 组织机构与职责

### 一、安全生产委员会

公司设立安全生产委员会（以下简称安委会），由公司主要负责人任主任，分管安全生产负责人任常务副主任，其他领导班子成员任副主任，各部门、车间主要负责人为成员。安委会是公司安全生产工作的最高领导决策机构，主要职责：

1. 贯彻执行国家安全生产方针政策和法律法规，研究决策公司安全生产重大事项；
2. 审定安全生产规章制度、年度安全工作计划、安全投入计划；
3. 定期召开安委会会议（每季度不少于一次），分析安全生产形势，研究解决重大问题；
4. 组织重大事故隐患的评估、整改和应急资源的配置决策；
5. 审定安全生产奖惩事项。

安委会下设办公室（设在安全管理部门），负责安委会日常工作。

### 二、安全管理部门职责

安全管理部门是公司安全生产的归口管理部门，主要职责：

1. 组织制定并监督实施安全生产规章制度和操作规程；
2. 组织开展安全教育培训、隐患排查治理和各类安全检查；
3. 审查特殊作业许可，监督现场安全措施落实；
4. 组织制定并管理应急预案，组织应急演练；
5. 负责劳动防护用品、安全设施的管理监督；
6. 参与新建、改建、扩建项目安全设施"三同时"管理；
7. 组织或参与事故调查处理，统计分析安全信息并按规定报告。

### 三、其他职能部门职责

生产、设备、技术、人事、采购、销售、行政后勤等部门按照"管业务必须管安全"的要求，对本业务范围内的安全生产工作负直接管理责任。例如：设备部门负责设备设施完整性和特种设备管理；技术部门负责工艺安全管理和变更管理；人事部门负责安全教育培训的计划实施和特种作业人员持证管理；采购部门负责供应商资质审查和安全协议签订。

## 第三章 主要负责人及各级领导安全职责

### 一、公司主要负责人职责

公司主要负责人（法定代表人、实际控制人、总经理）是公司安全生产第一责任人，对本单位安全生产工作全面负责：

1. 建立健全并落实全员安全生产责任制，加强安全生产标准化建设；
2. 组织制定安全生产规章制度和操作规程，审批重大安全管理事项；
3. 保证安全生产投入的有效实施，足额提取和使用安全生产费用；
4. 组织建立并落实安全风险分级管控和隐患排查治理双重预防工作机制，督促、检查安全生产工作，及时消除事故隐患；
5. 组织制定并实施生产安全事故应急救援预案；
6. 及时、如实报告生产安全事故，组织事故抢救和调查处理；
7. 每年向职工代表大会或者职工大会报告安全生产工作和个人履职情况，接受民主监督；
8. 依法组织制定并实施本单位安全生产教育和培训计划。

### 二、分管安全生产负责人职责

1. 协助主要负责人履行安全生产管理职责，对分管范围内的安全生产工作负直接领导责任；
2. 组织落实安委会决议和安全工作计划，主持日常安全管理工作；
3. 组织安全检查、隐患整改、考核奖惩和事故调查处理的具体实施；
4. 审批特殊作业许可，必要时到现场监督；
5. 定期向主要负责人和安委会报告安全生产情况。

### 三、其他领导班子成员职责

其他负责人按照"一岗双责"要求，对分管业务范围内的安全生产工作负领导责任，做到与生产经营工作同计划、同布置、同检查、同总结、同考核，及时协调解决分管范围内安全生产问题，参加并组织分管范围的安全检查和隐患整改。

### 四、车间主任（分厂厂长）职责

1. 车间主任是本车间安全生产第一责任人，对车间安全生产全面负责；
2. 组织落实各项安全规章制度和操作规程，制止和纠正违章指挥、违章作业；
3. 组织车间级安全教育和日常安全活动，开展岗位练兵；
4. 组织车间安全检查，落实隐患整改，对本车间无力解决的隐患按规定上报并采取临时控制措施；
5. 组织车间应急处置，参加事故抢险、报告和调查处理。

### 五、班组长职责

1. 班组长是班组安全生产直接责任人，组织本班组人员严格执行操作规程和劳动纪律；
2. 组织班前安全会，交代作业任务、风险和防范措施；组织班中巡查，纠正不安全行为；组织班后总结；
3. 检查班组设备工具和安全防护设施完好情况，发现问题及时处理或上报；
4. 组织新员工、转岗员工的岗位安全教育；
5. 发生事故时立即组织抢救、保护现场并如实报告。

## 第四章 员工安全职责与权利

### 一、从业人员安全生产义务

1. 遵守本单位安全生产规章制度和操作规程，服从管理，正确佩戴和使用劳动防护用品；
2. 接受安全教育培训，掌握本职工作所需的安全生产知识和技能，特种作业人员持证上岗；
3. 发现事故隐患或者其他不安全因素，立即向现场安全生产管理人员或者本单位负责人报告；
4. 参加应急演练，掌握本岗位应急处置和逃生自救技能。

### 二、从业人员安全生产权利

1. 有权了解其作业场所和工作岗位存在的危险因素、防范措施及事故应急措施；
2. 有权对本单位安全生产工作中存在的问题提出批评、检举、控告；
3. 有权拒绝违章指挥和强令冒险作业；
4. 发现直接危及人身安全的紧急情况时，有权停止作业或者在采取可能的应急措施后撤离作业场所；
5. 因生产安全事故受到损害的，除依法享有工伤保险外，依照民事法律尚有获得赔偿权利的，有权向本单位提出赔偿要求。公司不得因员工行使上述权利而降低其工资、福利等待遇或者解除劳动合同。

## 第五章 责任书签订与履职保障

1. 公司主要负责人与各部门、车间负责人签订年度安全生产责任书，车间与班组、班组与员工层层签订，实现全覆盖；
2. 安全生产责任书应明确责任目标、考核指标、奖惩标准，年末组织考核兑现；
3. 公司每年保障安全生产资金投入，用于隐患整改、安全设施维护、劳动防护用品配备、教育培训、应急演练等，不得挪作他用；
4. 公司依法为员工缴纳工伤保险，并根据岗位风险投保安全生产责任保险；
5. 新增岗位或职责调整时，应在一个月内完成责任制修订和责任书补签。

## 第六章 检查与考核

1. 责任制落实情况实行日常检查与年度考核相结合：安全管理部门每月抽查各部门、车间责任制执行情况；年终由安委会组织全面考核；
2. 考核内容包括：责任书签订与履职记录、安全检查与隐患整改完成情况、教育培训落实情况、违章违纪记录、事故指标控制情况等；
3. 考核结果分为优秀、合格、基本合格、不合格四个等次，与绩效奖金、评先评优、职务晋升挂钩；
4. 对考核不合格的单位和个人，取消当年评优资格，扣减相应绩效，主要负责人进行安全约谈。

## 第七章 奖惩规定

### 一、奖励

对有下列情形之一的单位和个人给予表彰奖励：全年实现安全生产目标、安全管理成效显著的；及时发现并报告重大事故隐患，避免事故发生的；在事故抢险救援中表现突出的；提出安全管理合理化建议被采纳实施的。奖励形式包括通报表扬、发放奖金、晋级晋档等。

### 二、处罚

对有下列情形之一的，视情节给予批评教育、经济处罚、待岗培训、纪律处分直至解除劳动合同：违章指挥、违章作业、违反劳动纪律的；擅自拆除、挪用、停用安全设施的；隐瞒事故隐患未报告的；教育培训考核不合格仍上岗作业的；对事故负有责任的。构成犯罪的，移送司法机关依法追究刑事责任。

### 三、责任追究

发生生产安全事故后，按照事故调查报告认定的责任，依规依纪依法追究相关人员的责任；对弄虚作假、隐瞒不报、迟报谎报的，从重处理；对在责任追究中打击报复举报人的，从严处理。

## 第八章 法规链接与实施要点

1. 主要法规依据：《中华人民共和国安全生产法》第四条关于全员安全生产责任制的规定、第二十一条关于主要负责人七项职责的规定、第五十七条关于从业人员义务的规定；《企业安全生产标准化基本规范》（GB/T 33000）关于机构设置与职责的要求。
2. 实施要点：责任制文本应做到层级清晰、用语具体、可考核可追溯，避免"谁都要负责、谁都负不了责"；职责条目应与岗位说明书、作业指导书保持一致，防止相互矛盾。
3. 佐证材料清单：责任书签订台账、履职评议记录、安委会会议纪要、考核兑现记录、责任制修订记录等，应作为安全生产标准化自评和安全检查的必备材料。
4. 本制度实施过程中发现职责空档或交叉的，由安全管理部门汇总提出修订建议，报安委会审议后发布修订版，并及时组织全员学习。

## 第九章 附则

1. 本制度由公司安全管理部门负责解释和修订，安委会审议通过后发布实施；
2. 各部门、车间可依据本制度制定实施细则，报安全管理部门备案；
3. 本制度与国家法律法规不一致的，按国家法律法规执行；
4. 本制度自发布之日起施行。
