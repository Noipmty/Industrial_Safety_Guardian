# 某污水处理企业有限空间中毒窒息事故

## 一、事故概况

某年6月9日15时30分许，某环保科技企业在其承建的某工业园区污水处理站进行污水调节池清淤作业时，发生一起有限空间中毒窒息事故。作业人员进入池内作业时硫化氢中毒晕倒，3名工友在未采取任何防护措施的情况下先后盲目下池施救，最终造成3人死亡、1人重伤的严重后果。事故直接经济损失约320万元，属于较大生产安全责任事故。

事发污水处理站由某环保公司运营，主要处理园区多家企业的工业废水，设计处理能力每天5000立方米。事发地点为调节池（有效水深约4.5米），池内长期沉积的污泥在高温天气下厌氧发酵，积聚大量硫化氢气体。6月上旬当地持续高温，为事故发生埋下了环境隐患。

## 二、事故经过

6月9日上午，污水处理站站长付某安排当天下午对1号调节池进行清淤。作业队伍为该环保公司临时组织的4人作业组，组长唐某，组员周某、吴某、郑某，均未经过有限空间作业专项培训，未办理任何作业审批手续。

14时30分，作业组打开调节池人孔盖，未进行通风，未使用气体检测仪检测，仅由唐某站在人孔口向下看了一下，认为"没什么味道，问题不大"。14时50分，周某（男，41岁）未佩戴任何呼吸防护用品、仅系一根普通麻绳，顺爬梯进入池内，站在池底清理淤泥。

15时05分，池内周某突然呼喊"头晕"随即倒地。人孔口的唐某见状，立即顺爬梯下池救人，下池后不到一分钟也倒在池底。在地面的吴某、郑某惊慌之下先后下池施救，吴某下池后也晕倒在爬梯旁，郑某下池行至半途感到四肢无力，拼命抓住爬梯被随后赶到的站内人员拉出。

15时20分，接到报告的站长付某赶到现场，此时他才想起库房有一台正压式空气呼吸器但过期未检、气瓶无气。付某组织人员用通风机向池内通风，同时拨打119、120。15时45分，消防救援人员佩戴空气呼吸器下池，将唐某、周某、吴某救出，三人经抢救无效死亡；郑某重伤，送医院救治后脱离生命危险。事后检测认定，池内硫化氢浓度峰值超过1000毫克每立方米，氧含量低至14%左右，属于典型的硫化氢中毒合并缺氧窒息。

## 三、直接原因分析

1. 调节池内沉积污泥厌氧发酵产生高浓度硫化氢并造成局部缺氧，作业人员周某未检测、未通风、未佩戴呼吸防护用品贸然进入池内作业，接触剧毒硫化氢中毒窒息死亡，是事故发生的直接原因；
2. 唐某、吴某先后在未佩戴任何呼吸防护用品的情况下盲目下池施救，造成伤亡扩大，是事故后果加重的主要原因；
3. 作业全过程未执行"先通风、再检测、后作业"的基本程序，未办理有限空间作业审批，通风、检测、监护、防护四项核心措施全部缺失。

## 四、间接与管理原因分析

1. 有限空间作业管理制度形同虚设。企业虽制定了有限空间作业规程和台账，但实际清淤作业未辨识、未审批、未交底，管理文件与现场作业"两张皮"；
2. 安全教育培训严重缺失。4名作业人员均不知道硫化氢的致命危害，未接受有限空间作业专项培训，未进行过应急演练，"盲目施救"是他们唯一会的"救援方式"；
3. 应急器材配备形同虚设。配备的正压式空气呼吸器长期无人维护、超期失效、气瓶无压，气体检测仪未配备，有限的应急资源在最需要时无法使用；
4. 企业对污水处理设施的风险辨识缺失。调节池、集水井等未被辨识为有限空间作业风险点，未设置警示标志和告知牌，作业组织者本人就是最大的"无知者"；
5. 外包与临时用工管理混乱。清淤任务临时安排、人员临时拼凑，无作业方案、无监护人、无签字确认，站长安排作业即视为"合法"；
6. 园区和企业主管部门对污水处理等辅助设施的有限空间作业监管存在盲区，日常检查重生产工艺、轻辅助设施。

## 五、责任追究与处理结果

依据《中华人民共和国安全生产法》《生产安全事故报告和调查处理条例》等法律法规，事故调查组认定该起事故是一起较大生产安全责任事故，处理结果如下：

1. 站长付某违章安排无防护清淤作业，对事故发生负有直接管理责任，移送司法机关依法追究刑事责任；
2. 组长唐某、组员周某、吴某违章作业和盲目施救，对事故发生负有直接责任，鉴于三人均已死亡，不再追究责任；
3. 环保公司总经理未履行安全生产管理职责，对事故负有主要领导责任，被追究相应刑事责任并处罚金；
4. 环保公司被处以罚款80万元，责令停产整顿，其污水处理运营资质和安全生产标准化等级被重新评定；
5. 向环保公司发包运营服务的园区管理公司未有效履行对承包单位的安全统一协调管理职责，被处罚款20万元；
6. 对属地负有监管职责的2名工作人员给予政务处分。

## 六、防范与整改措施

1. 全面开展有限空间再辨识、再建档。对污水处理设施、地下管网、储罐、料仓等逐一辨识登记，设置警示标志和安全告知牌，明确每个空间的主要危害因素和防护要求；
2. 严格执行"先通风、再检测、后作业"原则。有限空间作业必须办理作业审批，落实通风、检测（氧气、硫化氢、可燃气体）、持续监测、专人监护、进出登记等措施，检测数据记录存档，超标严禁进入；
3. 强制配备并维护应急器材。按作业点配齐正压式空气呼吸器、便携式四合一气体检测仪、三脚架、安全绳、安全带等，专人保管、定期检查、按期检验，确保随时可用；
4. 开展有限空间作业专项培训和演练。所有涉及有限空间作业和管理的人员必须培训考核合格，重点演练"发现人员倒地后的正确处置流程"，把"禁止盲目施救"刻进每名员工的头脑；
5. 严禁将清淤等有限空间作业发包给无资质、无能力的单位和个人，发包方必须对承包方作业方案、人员培训、防护装备进行审核和现场监督；
6. 建立作业前"一堂课、两检查"制度：作业前安全课讲清危害和处置，检查审批手续和检测记录，检查防护器材和通讯工具，缺一不开工；
7. 将辅助生产设施纳入隐患排查和监管范围，消除监管盲区，对高温季节污泥发酵产气等季节性风险提前预警、加密检测。

## 八、事故链复盘与法规链接

### 一、事故链复盘

本起事故的事故链可概括为：清淤作业未辨识未审批（准入失效）→ 不通风不检测直接进入（程序失效）→ 无任何呼吸防护（装备失效）→ 人员中毒倒地（险情发生）→ 工友盲目下池施救（应急失效）→ 空气呼吸器过期无气（保障失效）→ 三人死亡。从第一人到第四人遇险不足三十分钟，每一个环节都是可预防的，"先通风、再检测、后作业、有监护、不盲救"五项要求全部落空。

### 二、法规标准链接

1. 《工贸企业有限空间作业安全规定》（应急管理部令第13号）：企业应当对有限空间进行辨识、建立管理台账，作业必须履行审批手续，落实"先通风、再检测、后作业"要求，配备必要的防护和应急装备；
2. 《中华人民共和国安全生产法》第一百零二条关于未落实有限空间作业安全措施的法律责任；
3. GB 30871-2022《危险化学品企业特殊作业安全规范》第11章受限空间作业要求；
4. GBZ/T 205《密闭空间作业职业危害防护规范》；
5. GB 16556《自给开路式压缩空气呼吸器》关于呼吸器配备、检验和维护的要求。

### 三、同类事故多发环节自查清单

1. 污水池、集水井、管网、储罐、料仓等是否完成有限空间辨识并建立台账、设置警示标识；
2. 作业审批、通风、检测、监护、进出登记是否逐项落实并如实记录；
3. 正压式空气呼吸器、四合一气体检测仪、三脚架、安全绳是否按点配备、按期检验、随时可用；
4. 员工是否经过有限空间专项培训并演练"禁止盲目施救"处置流程；
5. 清淤、疏通等外包作业是否审核承包方能力和作业方案，是否落实现场监护。

### 四、夏季高温时段特别提示

每年6月至9月是有限空间中毒窒息事故高发期，高温加速污泥发酵和有害气体挥发，企业应：加密巡检频次，发现异味异常立即排查；清淤等高风险作业避开高温时段，尽量安排在早晨进行；作业前连续机械通风不少于30分钟并全程保持；气体检测频次加密至每小时一次；为监护人配备双人备份的通讯和报警工具。

## 九、事故教训与警示

1. 无知比风险更可怕。三名遇难者至死都不知道池里是什么气体在杀人，有限空间事故的根源是"不知道有危险"，教育培训必须先于作业、必须讲到每个人的恐惧感为止；
2. "先通风、再检测、后作业"是用无数生命换来的铁律。本案中通风、检测、防护、监护四道防线一道都没有设，任何一个环节到位，事故都不会发生；
3. 盲目施救是有限空间事故伤亡扩大的第一杀手。一人遇险、多人搭上性命的悲剧反复上演，必须让每个员工记住：见人倒地，先报警、先防护、再施救，不佩戴空气呼吸器绝对不能下池；
4. 应急器材"配而不用、用而失效"等于没有。失效的空气呼吸器在这起事故中就是最讽刺的注脚，应急装备必须定期检查、定点存放、专人负责、动态更新；
5. 污水处理、地下管网等"不起眼"的辅助设施，恰恰是有限空间事故的高发区，企业和管理部门必须把辨识、培训、装备、审批四项基础工作做实做到位。
